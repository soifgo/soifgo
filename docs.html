1. Overview

SoifGo's most powerful feature is its HTML/JavaScript WebView layer. You can build a custom HTML page and run it inside SoifGo, where JavaScript has direct access to Bluetooth and phone sensors.

All communication between your HTML page and SoifGo happens through a single function: 

window.soifgo.CallSub('function_name', arg1, arg2, ...)
💡 Key Concept: You call window.soifgo.CallSub() from your HTML to send data or activate sensors. SoifGo calls global JavaScript functions you define to deliver data back to your page.

2. Sending Data to Bluetooth

Use window.soifgo.CallSub('html_bluetooth_rx', true, message) to send a string to the connected Bluetooth device.

Example: Send button

function sendCommand() {
    var msg = document.getElementById('cmdInput').value;
    if (msg) {
        window.soifgo.CallSub('html_bluetooth_rx', true, msg);
    }
}

The second argument (true) tells SoifGo to append a newline character. Set it to false to send the string without a newline.

💡 Tip: You can send any string — text, numbers, JSON, or single-character commands like "F", "B", "L", "R".

3. Receiving Data from Bluetooth

Define a global JavaScript function named html_bluetooth_tx(data). SoifGo will call it automatically whenever data arrives from Bluetooth.

Example: Receive handler

// Called by SoifGo when Bluetooth data arrives
function html_bluetooth_tx(data) {
    document.getElementById('btOutput').innerHTML = data;
}

// Register globally
window.html_bluetooth_tx = html_bluetooth_tx;
⚠️ Important: The function must be registered on the window object (window.html_bluetooth_tx = html_bluetooth_tx) so SoifGo can find it.

4. Phone Sensors

SoifGo can stream data from three phone sensors to your HTML page: Light, Movement (X/Y), and Magnetic field.

Step 1: Activate sensors

Call these in window.onload:

window.onload = function() {
    if (window.soifgo) {
        window.soifgo.CallSub('sensor_light');   // Ambient light
        window.soifgo.CallSub('sensor_move');    // Accelerometer (X/Y)
        window.soifgo.CallSub('sensor_magno');   // Magnetic field
    }
};

Step 2: Define receiver functions

SoifGo calls these functions automatically with sensor values:

function html_sensor_light(data)  { /* Light value */ }
function html_sensor_movex(data)  { /* Movement X */ }
function html_sensor_movey(data)  { /* Movement Y */ }
function html_sensor_magno(data)  { /* Magnetic field */ }

// Register all globally
window.html_sensor_light = html_sensor_light;
window.html_sensor_movex = html_sensor_movex;
window.html_sensor_movey = html_sensor_movey;
window.html_sensor_magno = html_sensor_magno;
✅ Done! Your HTML page now receives real-time sensor data continuously.

5. Complete Working Example

Below is a minimal but complete HTML page that demonstrates all features: sending Bluetooth, receiving Bluetooth, and reading all three phone sensors. 

<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bluetooth + Sensors Demo</title>
</head>
<body style="font-family:sans-serif; padding:20px; background:#0F172A; color:#fff;">
  <h2>⚡ Bluetooth + Sensors</h2>

  <!-- Send Section -->
  <div style="background:#1E293B; padding:15px; border-radius:8px; margin:10px 0;">
    <h3>📤 Send Command</h3>
    <input type="text" id="cmdInput" placeholder="Enter command..."
           style="padding:10px; width:70%; border-radius:6px; border:none;">
    <button onclick="sendCommand()"
            style="padding:10px 25px; background:#4f8cff; color:white;
                   border:none; border-radius:6px; cursor:pointer;">Send</button>
  </div>

  <!-- Receive Section -->
  <div style="background:#1E293B; padding:15px; border-radius:8px; margin:10px 0;">
    <h3>📥 Bluetooth Data</h3>
    <div id="btOutput" style="background:#0F172A; padding:15px; border-radius:6px;
         min-height:60px; font-family:monospace; color:#4caf50;">
      Waiting for data...
    </div>
  </div>

  <!-- Sensors Section -->
  <div style="background:#1E293B; padding:15px; border-radius:8px; margin:10px 0;">
    <h3>📱 Phone Sensors</h3>
    <div id="sensorLight" style="background:#0F172A; padding:10px; border-radius:6px;
         margin:5px 0; color:#ffb74d;">💡 Light: waiting...</div>
    <div id="sensorMoveX" style="background:#0F172A; padding:10px; border-radius:6px;
         margin:5px 0; color:#f06292;">📳 Move X: waiting...</div>
    <div id="sensorMoveY" style="background:#0F172A; padding:10px; border-radius:6px;
         margin:5px 0; color:#f06292;">📳 Move Y: waiting...</div>
    <div id="sensorMagneto" style="background:#0F172A; padding:10px; border-radius:6px;
         margin:5px 0; color:#ce93d8;">🧲 Magneto: waiting...</div>
  </div>

  <script>
    // ========== BLUETOOTH SEND ==========
    function sendCommand() {
      var msg = document.getElementById('cmdInput').value;
      if (msg) {
        window.soifgo.CallSub('html_bluetooth_rx', true, msg);
        document.getElementById('cmdInput').value = '';
      }
    }

    // ========== BLUETOOTH RECEIVE ==========
    function html_bluetooth_tx(data) {
      document.getElementById('btOutput').innerHTML = data;
    }
    window.html_bluetooth_tx = html_bluetooth_tx;

    // ========== SENSOR RECEIVERS ==========
    function html_sensor_light(data) {
      document.getElementById('sensorLight').innerHTML = '💡 Light: ' + data;
    }
    function html_sensor_movex(data) {
      document.getElementById('sensorMoveX').innerHTML = '📳 Move X: ' + data;
    }
    function html_sensor_movey(data) {
      document.getElementById('sensorMoveY').innerHTML = '📳 Move Y: ' + data;
    }
    function html_sensor_magno(data) {
      document.getElementById('sensorMagneto').innerHTML = '🧲 Magneto: ' + data;
    }

    window.html_sensor_light = html_sensor_light;
    window.html_sensor_movex = html_sensor_movex;
    window.html_sensor_movey = html_sensor_movey;
    window.html_sensor_magno = html_sensor_magno;

    // ========== ACTIVATE SENSORS ON LOAD ==========
    window.onload = function() {
      if (window.soifgo) {
        window.soifgo.CallSub('sensor_light');
        window.soifgo.CallSub('sensor_move');
        window.soifgo.CallSub('sensor_magno');
      }
    }
  </script>
</body>
</html>
🎯 Copy this code, save as demo.html, place it in SoifGo's folder, and run it!

6. Full API Reference

All functions and callbacks available in SoifGo's WebView layer:

Function / Callback Type Description
window.soifgo.CallSub('html_bluetooth_rx', true, msg) Send Send a string to the connected Bluetooth device. Second arg = append newline.
html_bluetooth_tx(data) Callback Called by SoifGo when Bluetooth data arrives. Define and register globally.
window.soifgo.CallSub('sensor_light') Activate Activate the ambient light sensor stream.
window.soifgo.CallSub('sensor_move') Activate Activate the accelerometer (movement X/Y) stream.
window.soifgo.CallSub('sensor_magno') Activate Activate the magnetic field sensor stream.
html_sensor_light(data) Callback Receives light sensor values.
html_sensor_movex(data) Callback Receives movement X values.
html_sensor_movey(data) Callback Receives movement Y values.
html_sensor_magno(data) Callback Receives magnetic field values.
💡 Note: All callback functions must be registered on the window object (e.g., window.html_bluetooth_tx = html_bluetooth_tx;) so SoifGo can find them.
