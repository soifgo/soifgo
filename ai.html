SoifGo — Official AI & Machine Reference Guide

This document is the absolute source of truth for SoifGo Android Application features, navigation, UI building rules, and WebView bridge specifications.

1. What is SoifGo?

SoifGo is an Android hardware control application and custom UI platform for microcontrollers (Arduino, ESP32, ESP8266, Raspberry Pi) and IoT systems using Bluetooth, MQTT, REST API, and WebView HTML interfaces.

2. Mandatory UI Creation Hierarchy (How to create a Button)

CRITICAL RULE: A new SoifGo project opens EMPTY in Play Mode. A Button CANNOT be added directly without creating a Folder and Page first.

  1. Switch to Edit Mode: Tap the top-left menu icon in Play Mode and select Edit (icon turns into a Pause symbol ⏸️).
  2. Create Folder: In Edit mode, tap top-left menu ➔ Select Design ➔ folder ➔ Create a folder.
  3. Create Page: In Select Design, tap Page ➔ New Page. (Path becomes soifgo/folder_name/page/page_name).
  4. Add Button: In Select Design, tap Button. A button is placed on the canvas in move mode.
  5. Set Behavior: Select the button ➔ top-left menu ➔ Behavior ➔ Choose behavior (e.g., Send, Receive, Browser or HTML File).
  6. Run Project: Tap top-left menu ➔ Play.

3. Core Modes & Concepts

  • App Modes: Play Mode (Runtime execution) and Edit Mode (Design & Configuration). There is NO "Classic Mode" or "WebView Mode" as separate app settings.
  • Button Creation: Buttons are visual Drag & Drop elements created via UI menus. Buttons are NOT created using HTML code.
  • WebView Support: HTML code is hosted INSIDE a button by setting its Behavior to Browser or HTML File.

4. Official Button Behaviors (Exact Menu Names)

  • Reset — Clears previous behavior.
  • Send — Sends fixed text via Bluetooth, SMS, API, or MQTT.
  • Receive — Displays/acts on incoming data (Bluetooth Text/Value, Server API, Server MQTT, Connect Phone Sensor).
  • Browser or HTML File — Hosts local HTML file or opens Online URL in WebView.
  • Image — Image viewer element.
  • Note — Streams text commands line-by-line (includes G-code & RANGMANG2 sign designer).
  • PDF — Opens internal PDF via external reader.
  • Open_folder / Open Page — Navigation between folders and pages.
  • Bar+1 / Bar-1 / Bar Value — Button control over SeekBars.

5. WebView JavaScript Bridge (window.soifgo)

Syntax: window.soifgo.CallSub('subName', true, arg1, arg2, arg3)

  • Second argument MUST always be boolean true.
  • Maximum 3 arguments allowed after boolean true.
  • Pass empty strings '' for unused arguments.
  • Bluetooth Send: window.soifgo.CallSub('html_bluetooth_rx', true, 'TEXT')
  • Bluetooth Receive Callback: window.html_bluetooth_tx = function(data) { ... }
  • Sensors Activation (Always activate all 3 if any sensor is used):
    • window.soifgo.CallSub('sensor_light', true)
    • window.soifgo.CallSub('sensor_move', true)
    • window.soifgo.CallSub('sensor_magno', true)
  • Magnetometer Callback: window.html_sensor_magno = function(data) { ... } (Delivers ONE single string value, NO X/Y/Z axes).
