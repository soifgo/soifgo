⚙️ CMI209

Android CNC Controller – Open Source

CMI209 is a lightweight, open-source CNC control module designed to work through an Android mobile interface.

Based on the ATmega328P microcontroller, it reliably receives and executes standard G-code commands over Bluetooth at 115200 baud.

Whether you prefer typing raw G-code, loading externally prepared files, sketching with mini-codes on your phone, or manually controlling the machine via the dashboard, CMI209 gives you the freedom to choose the method that best fits your workflow — all in a portable, computer-free environment.

📋 Overview

CMI209 is a CNC-like module based on the ATmega328P microcontroller. It is controlled by the Soifgo Android app through the CMI (CNC Mobile Interface). Communication is done via a Bluetooth module at a baud rate of 115200.

📌 Note

Before using the Bluetooth module, it must be set to 115200 baud.

The following files are included in the project: PCB file, programmer file, BASCOM file, Proteus file, and reference images. All of these files are available for download at the end of the page.

💾 Saved Settings

The following settings are stored in EEPROM memory:

pulse=100

This means that 100 pulses move the stepper motor by 1 mm in this project. If you use a different device, adjust the pulses per millimeter value in Soifgo. 

Max_x=40
Max_y=40
Max_z=40

The maximum travel range for the X, Y, and Z axes is 40 mm for this setup. 

feedm=1200

Default movement speed is set to 1400 mm/min. If no speed is received, the module uses the stored/default speed value. 

feeds=5.7

This is the speed correction coefficient used to match the machine behavior. In this device, the measured value is 5.7.

📟 Command Reference

🔹 Position Commands

Values are in millimeters, and uppercase letters must be used.

Command Description Example
X<value> Move X axis to position X12
Y<value> Move Y axis to position Y2
Z<value> Move Z axis to position (negative allowed) Z-3
resetx Zero the X axis resetx
resety Zero the Y axis resety
resetz Zero the Z axis (set work surface) resetz

🔹 Spindle & Feed

Command Description Example
S<value> Set spindle speed (0–20,000 RPM) S12000
F<value> Set feed rate (1–4800 mm/min) F600
W<value> Auxiliary PWM output (0–1024) W510

🔹 Arc & Circle

Parameter Description Example
A Starting angle (0–360) A0
B Ending angle (0–360) B360
R Radius R10
X Center X coordinate X20
Y Center Y coordinate Y20
Z Depth (negative value) Z-1

Example: A full circle with 10 mm radius at X=20, Y=20, depth 1 mm:

Z5
A0B360X20Y20Z-1

📌 Arc Resolution

The number of points used to generate the circle is initially set to 50. Use res23 to change resolution (up to 99 for higher precision, or lower for polygon shapes).

🔹 Delay

Create a delay in seconds (1–300):

sec2

🔹 Precise Movement

Manual movement in small increments (0.001–999 mm) using signed lowercase commands: 

+x0.5
-x0.5
+y0.5
-y0.5
+z0.5
-z0.5

🔹 Homing & Safety

Command Description
G28 Homing (standard G-code)
home Homing (module command)
stop Emergency stop
resetall Reset after fault/stop

🔹 Limit Switches

Three normally-open switches should be installed for X home, Y home, and Z home. The Z home switch should allow some extra travel, at least 6 mm to 10 mm.

🔌 Wiring & Connections

Stepper Driver Connections

The module uses three stepper motor driver modules. For external drivers, use the four pins provided for each axis: 

GND
ENABLE
STEP
DIR

Bluetooth Module

Connect an HC-05 or HC-06 Bluetooth module to the UART pins:

  • VCC → 5V
  • GND → GND
  • TX → RX (of ATmega)
  • RX → TX (of ATmega)

❓ Frequently Asked Questions

🔹 What is the default baud rate?
Default is 115200. This must match the Bluetooth module configuration.
🔹 How do I change the pulses per millimeter?
Adjust the pulse value in the EEPROM settings or configure it in the Soifgo app.
🔹 Can I use external stepper drivers?
Yes. Use the STEP, DIR, ENABLE, and GND pins provided for each axis.
🔹 How do I reset the module after an emergency stop?
Send resetall command through Soifgo or power-cycle the module.
🔹 What is the maximum spindle speed?
Up to 20,000 RPM with PWM control (0–1024).
🔹 Can I use this for laser engraving?
Yes. Use the auxiliary PWM output (W command) for laser power control.
