🌈 RANGMANG

Open-Source RGB LED Strip Controller

RANGMANG is a lightweight RGB controller built around the ATmega128 and ATmega328P microcontrollers for controlling addressable LED strips.

It supports WS2811, WS2812B, WS2813, WS2815, SK6812, APA102, and other compatible LEDs.

Using a simple serial protocol over Bluetooth or USB, RANGMANG allows Android devices running Soifgo to control colors, effects, animations, and multiple LED controllers without requiring firmware modifications.

📋 Overview

RANGMANG is a controller for programmable RGB LED strips, supporting WS2811, WS2812, WS2815, and other addressable LED families.

The purpose behind creating RANGMANG is to provide a standardized and easy‑to‑use interface for controlling LED strips. With a simple serial connection — whether via Bluetooth or a USB‑serial converter — and a defined command format, you can quickly and easily apply custom changes to the LED strips.

The system is designed for up to 98 parallel modules. The software is optimized for working with the Soifgo Android application, but you can use any serial terminal to send commands.

📟 Command Reference

RANGMANG uses a simple text-based protocol over serial. All commands are case-sensitive and should be sent as plain text.

🔹 Mode Selection

Command Description
D0 Static Color Mode — set colors using R/G/B commands
D1 – D55 Built-in lighting effects (Rainbow, Chase, Fade, Strobe, etc.)
D99 Random Mode — mixes and plays all effects randomly

🔹 Static Color Commands

Command Description Example
R<value> Red channel (0–255) R255
G<value> Green channel (0–255) G128
B<value> Blue channel (0–255) B64

🔹 Effect Control

Command Description Example
S<value> Animation speed / first delay (ms) (0–999) S50
E<value> Second delay (ms) for effects (0–999) E30
M<value> Number of active pixels (ATmega128: 1–999, ATmega328: 1–450) M120

🔹 Addressing & Memory

Command Description Example
A<value> Select module address (1–98, 99 = all) A5
CH<old>=<new> Change module address CH1=5
M996 Erase strip + clear memory M996
M997 Clear LEDs (turn off all pixels) M997
M998 Fill LEDs with current color M998
M999 Save full strip configuration to memory slot 1 M999

🔹 Example Sequences

Static Color (ATmega128 - 999 pixels):

A1D0R200G50B100S1E120M10

Dance Mode (Random Colors):

A1D12R251G251B251S1E1M128

Change Module Address:

CH1=3

🔌 Wiring & Power Guide

⚡ Power Supply

⚠️ IMPORTANT

Always check your LED strip voltage before connecting power!

  • WS2812B / SK6812 / APA102: 5V strips — connect a 5V power supply directly. Remove the 12V-to-5V regulator and bridge the input to output.
  • WS2811 / WS2815: 12V strips — use a 12V power supply and keep the 12V-to-5V regulator on the board.
  • Current: Each LED draws ~50mA at full brightness (white). Calculate total current: LED count × 0.05A. Use a power supply with at least 20% headroom.
  • Data Line: Connect the LED data line to the DIN pin of the RANGMANG board.
  • GND: Always connect LED ground to the board ground. This is critical for stable data transmission.
  • Reverse Polarity Protection: To prevent reverse connection of the LED strip, use a properly keyed connector. Add a diode in series with the microcontroller's power input for protection.

🔗 Bluetooth Module

Connect an HC-05 or HC-06 Bluetooth module to the UART pins of the microcontroller:

  • VCC → 5V
  • GND → GND
  • TX → RX (of ATmega)
  • RX → TX (of ATmega)

📌 Bluetooth Power Jumper

If the module is used individually, connect the Bluetooth power jumper.
If modules are used in parallel, only connect the jumper for the module linked to Bluetooth and disconnect the rest.

The Bluetooth module must be configured to 115200 baud using AT commands before use.

📡 USB-Serial Connection

You can also connect directly via a USB-to-Serial adapter (e.g., FTDI, CP2102) to the same UART pins for debugging or firmware upload.

📡 Module Addressing Instructions

Each module has a unique address (1–98). Address 99 is a shared address that applies to all modules.

To change a module's address:

CH old_address = new_address

Examples:

CH1=3    (Changes module 1 to address 3)
CH23=47  (Changes module 23 to address 47)

Important: After programming, all modules have an initial default address of 1. Therefore, during the first addressing, the old (current) address is always 1.

After changing the address, the module will respond using its new address. For example, if the new address is 3, the module will reply to: A3

🔄 WS2811 Green/Blue Color Swap

When working with WS2811 LED strips, you might notice that Green and Blue are swapped. This is a common issue due to hardware layout designs.

❓ Why Does This Happen?

  • WS2812 LEDs typically use internal GRB or standard RGB color ordering.
  • WS2811 ICs are external controllers. To simplify PCB routing, manufacturers frequently cross-wire the Green and Blue output pins to the LED.
  • As a result, the strip ends up behaving as an RBG (Red, Blue, Green) device instead of standard RGB.

✅ Solution in Soifgo

In the Soifgo app settings, tap on the RGB label to switch it to RBG.
This automatically swaps Green and Blue during data transmission, ensuring accurate colors.

💻 Developer Note

If you are writing custom firmware for WS2811, you must manually swap Green and Blue values: 

Intended Color:    R: 10, G: 123, B: 44
Code for WS2811:   R: 10, G: 44,  B: 123

❓ Frequently Asked Questions

🔹 Why doesn't my LED strip light up?
Check power supply, ground connection, and data line polarity. Ensure your strip voltage matches the board (5V or 12V). Also verify the baud rate is 115200.
🔹 Can I use WS2815 12V strips?
Yes! WS2815 is fully supported. Use a 12V power supply and keep the 12V-to-5V regulator on the board.
🔹 What is the maximum number of LEDs?
ATmega128 supports up to 999 LEDs. ATmega328P supports up to 450 LEDs.
🔹 How do I set the Bluetooth baud rate?
Use AT commands: AT+UART=115200,0,0 for HC-05 or HC-06 modules. Ensure you're in AT command mode.
🔹 Can I control multiple modules independently?
Yes. Use the A<value> command to select up to 98 modules. Each module stores its own configuration.
🔹 Why are Green and Blue swapped on my WS2811 strip?
WS2811 strips often use RBG order instead of RGB. In Soifgo, switch the setting to RBG, or swap G and B values in your code.
🔹 What is the default baud rate?
Default is 115200. This is configured in the firmware and must match the Bluetooth module.
🔹 How do I reset the module?
Power cycle the board or send M997 to clear LEDs and M996 to erase memory.
