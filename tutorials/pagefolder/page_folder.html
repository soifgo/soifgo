🧭 Navigation in SoifGo

💡 Use folders and subfolders to organize your designs and navigate between pages easily.

In SoifGo you can create multiple branches such as folders and subfolders. Each folder may contain separate pages, and these pages remain independent.

📄 Page Opening Behavior

With the page-opening behavior, you can assign a button to load another page you have designed. From that page, you can also navigate back to the previous one.

🗂️ Folder Opening Behavior

Sometimes you need to access pages located in another folder. In this case, simply choose the folder-opening behavior and select the desired folder.

Navigation Features

📁 Folders Create multiple folders and subfolders to organize your designs
📄 Pages Each folder can contain separate, independent pages
🔗 Page Opening Assign a button to load another page with back navigation
🗂️ Folder Opening Access pages in other folders directly

Important Note

Make sure each page has a clear purpose and avoid creating too many nested folders. A simple structure is easier to maintain and faster to navigate.

  • Use meaningful names for folders and pages.
  • Keep the navigation flow consistent across all pages.
  • Test the back navigation behavior after each change.
