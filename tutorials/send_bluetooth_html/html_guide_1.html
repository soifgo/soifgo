SoifGo turns your HTML pages into a real Android app. Inside its WebView, your page can talk to Bluetooth, read phone sensors, connect to MQTT brokers, and store data — all with plain HTML, CSS, and JavaScript.

This guide shows you how to:

  • ✅ Send and receive Bluetooth data

  • ✅ Save and reload data with localStorage

🔌 The Bridge — How HTML Talks to SoifGo

Inside SoifGo's WebView, a JavaScript object called window.soifgo is automatically injected. Use it to call native functions from JavaScript.

📄 Bridge call pattern
// Basic call pattern
window.soifgo.CallSub('subName', true, arg1, arg2, arg3);

// Real example — send text to Bluetooth
window.soifgo.CallSub('html_bluetooth_rx', true, txt);

// Real example — connect to MQTT broker (step 1)
window.soifgo.CallSub('connecte_mqtt_ai', true, address, id);
✅ Golden rules:
  • Always call window.soifgo.CallSub(...) directly.
  • The second argument is a boolean flag — pass true or false.
  • After the flag, you can pass up to 3 arguments.
  • Empty strings must still be passed as '' — never omit them.

🔵 1. Bluetooth - Send Data (WebView → SoifGo → Bluetooth)

This page allows the user to enter text and send it via Bluetooth. The data goes from the WebView to SoifGo, then to the connected Bluetooth device.

📄 html_bluetooth_send.html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Send Command</title>
</head>
<body style="text-align:center; margin-top:50px; font-family:sans-serif;">

  <h3>📤 Send Command to Bluetooth</h3>
  <input type="text" id="txt" placeholder="Enter text...">
  <br><br>
  <button onclick="sendBluetooth()"
          style="padding:10px 30px; font-size:16px; background:#2196f3;
                 color:white; border:none; border-radius:6px; cursor:pointer;">
    Send
  </button>

  <script>
    function sendBluetooth() {
      const txt = document.getElementById('txt').value;
      window.soifgo.CallSub('html_bluetooth_rx', true, txt);
    }
  </script>
</body>
</html>
✅ How it works:
  1. User types text in the input box.
  2. Clicks the Send button.
  3. JavaScript calls window.soifgo.CallSub('html_bluetooth_rx', true, txt).
  4. SoifGo sends the text to the connected Bluetooth device.

This page displays data received from Bluetooth. SoifGo forwards incoming data to the WebView using JavaScript functions.

✅ How it works:
  1. Bluetooth device sends data to SoifGo.

  3. JavaScript updates the page with the received data.

🟢 3. Sensor Data - Receive (Sensors → SoifGo → WebView)

This page displays data from 3 sensors:

  • Light - Light intensity sensor
  • Move X/Y - Movement/acceleration sensor (X and Y axis)
  • Magneto - Magnetic field sensor
⚠️ IMPORTANT: To activate sensors, you must call ALL THREE commands: 
window.soifgo.CallSub('sensor_light', true);   // Activate light sensor
window.soifgo.CallSub('sensor_move', true);    // Activate movement sensor
window.soifgo.CallSub('sensor_magno', true);   // Activate magneto sensor

These 3 commands are called inside window.onload to auto-start sensors when the page loads.

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Sensor Receive</title>

<body>
    <div id="light"  style="font-size:20px;color:white;background:#333;padding:15px;margin:5px;border-radius:8px;">
        Light: waiting...
    </div>
    <div id="movex"  style="font-size:20px;color:white;background:#444;padding:15px;margin:5px;border-radius:8px;">
        Move X: waiting...
    </div>
    <div id="movey"  style="font-size:20px;color:white;background:#555;padding:15px;margin:5px;border-radius:8px;">
        Move Y: waiting...
    </div>
    <div id="magno"  style="font-size:20px;color:white;background:#666;padding:15px;margin:5px;border-radius:8px;">
        Magneto: waiting...
    </div>

    <script>
        // ---- Receiver functions (called by SoifGo) ----
        function html_sensor_light(data) {
            document.getElementById('light').innerHTML = 'Light: ' + data;
        }
        function html_sensor_movex(data) {
            document.getElementById('movex').innerHTML = 'Move X: ' + data;
        }
        function html_sensor_movey(data) {
            document.getElementById('movey').innerHTML = 'Move Y: ' + data;
        }
        function html_sensor_magno(data) {
            document.getElementById('magno').innerHTML = 'Magneto: ' + data;

            window.soifgo.CallSub('sensor_light', true);

        };
    </script>

</html>
✅ How it works:
  1. 3 activation commands in window.onload:
    • window.soifgo.CallSub('sensor_light', true)
    • window.soifgo.CallSub('sensor_move', true)
    • window.soifgo.CallSub('sensor_magno', true)
    These activate all three sensors when the page loads.
  2. 4 receiver functions registered in window:
    • html_sensor_light(data) — receives light data
    • html_sensor_movex(data) — receives move X data
    • html_sensor_movey(data) — receives move Y data
    • html_sensor_magno(data) — receives magneto data
    SoifGo calls these functions when new sensor data arrives.
  3. UI updates automatically — each function updates its corresponding div.

🟣 4. MQTT — Connect, Publish & Receive (WebView ↔ Broker)

SoifGo has a built-in MQTT client. Your HTML page can connect to any MQTT broker, publish messages, and receive them — all through simple JavaScript calls. No WebSocket, no CORS, no external library needed.

⚠️ IMPORTANT: MQTT only works inside SoifGo's WebView. If you open the same HTML in a normal browser, the bridge won't exist and nothing will happen (that's by design — the page won't crash either).
📄 MQTT API Reference
// ============================================================
// 1. CONNECT — step 1: address + client id
// ============================================================
// Native Sub: connecte_mqtt_ai(address, id)
//
//  address : "tcp://host:1883"  or  "ssl://host:8883"
//            Empty → defaults to "tcp://test.mosquitto.org:1883"
//  id      : any unique string. Empty → auto-generated "soifgo_XXXX"
//
window.soifgo.CallSub('connecte_mqtt_ai', true, address, id);

// ============================================================
// 2. CONNECT — step 2 (optional): username + password
// ============================================================
// Native Sub: connecte_mqtt_up(username, password)
//
// Only call this if the broker requires authentication.
// If both are empty, nothing happens.
//
window.soifgo.CallSub('connecte_mqtt_up', true, username, password);

// ============================================================
// 3. PUBLISH a message (also subscribes to the same topic!)
// ============================================================
// Native Sub: mqtt_publish(topic, message, qos)
//
//  topic   : topic string (e.g. "soifgo/led")
//  message : text payload
//  qos     : "0", "1", or "2"  (as a string)
//
// 💡 Publishing to a topic also subscribes you to it,
//    so you receive messages published by other clients.
//
window.soifgo.CallSub('mqtt_publish', true, topic, message, qos);

// ============================================================
// 4. DISCONNECT from the broker
// ============================================================
// Native Sub: mqtt_Disconnect  (no arguments)
//
window.soifgo.CallSub('mqtt_Disconnect', true);

// ============================================================
// 5. CHECK connection status
// ============================================================
// Native Sub: mqtt_status  (no arguments)
// SoifGo replies by calling html_mqtt_status('true'/'false')
//
window.soifgo.CallSub('mqtt_status', true);

// ============================================================
// RECEIVERS — functions SoifGo calls on your page
// ============================================================

// Incoming message on a subscribed topic
function mqtt_rx(topic, message) {
    // topic   : string
    // message : string
}
window.mqtt_rx = mqtt_rx;

// Connection status changed
// ⚠️ The value is sent as a STRING ('true' or 'false'),
//    NOT as a real boolean. Convert it before using it!
function html_mqtt_status(connected) {
    const isConnected = (connected === true || connected === 'true');
    // use isConnected (true/false)
}
window.html_mqtt_status = html_mqtt_status;
✅ How it works:
  1. Your page calls connecte_mqtt_ai(address, id) to start the connection.
  2. If the broker needs auth, call connecte_mqtt_up(username, password) right after.
  3. When a message arrives on a subscribed topic, SoifGo calls mqtt_rx(topic, message).
  4. Publishing with mqtt_publish also auto-subscribes you to that topic — so you receive messages from other clients on it.
  5. To query connection state, call mqtt_status — SoifGo answers with html_mqtt_status('true') or ('false').
  6. To stop, call mqtt_Disconnect.

        function log(msg) {

            const t  = new Date().toLocaleTimeString();
            el.innerHTML += `<div>[${t}] ${msg}</div>`;
            el.scrollTop = el.scrollHeight;

🔧 MQTT Troubleshooting

Connection fails immediately
Check the broker URL. Use tcp:// for plain, ssl:// for TLS. Default ports: 1883 (plain), 8883 (TLS).
Messages not arriving
Publish at least once to the topic you want to listen to — publishing auto-subscribes you. Also verify the topic name is exactly the same (MQTT is case-sensitive).
Status always shows "Connected"
The status value arrives as a string ('true' / 'false'). In JavaScript the string 'false' is truthy — always compare with === 'true'.
Client ID conflict
If two clients use the same ID, the broker kicks one off. Leave the ID empty to get a unique auto-generated one.
Bridge not found
If window.soifgo is undefined, you're running in a normal browser — the bridge only exists inside SoifGo.

💾 5. Save & Reload Data (Persistent Storage)

✅ Good news: alert(), confirm(), and prompt() all work natively in SoifGo's WebView. You can use standard browser dialogs in your code.
💡 Tip: If you want a fully themed look that matches your UI, build a custom HTML modal.

Use localStorage to save and reload data. It persists across page reloads and WebView restarts, so your users never lose their settings.

📄 html_storage.html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Save & Reload</title>
    <style>
        body { font-family: sans-serif; background:#1e1e1e; color:#e0e0e0; padding:16px; }
        input, button { padding:10px; border-radius:6px; border:1px solid #444;
                        background:#2b2b2b; color:#fff; font-size:16px; margin:4px 0; }
        button { background:#3498db; border:none; cursor:pointer; }
        button.danger { background:#c0392b; }
        .row { display:flex; gap:8px; align-items:center; margin:4px 0; }
        .row button { flex:0 0 auto; }
        #output { margin-top:16px; }
        .item { padding:8px 12px; background:#2b2b2b; border-radius:6px;
                margin:4px 0; display:flex; justify-content:space-between; }
        .item .time { color:#888; font-size:0.85rem; }
    </style>
</head>
<body>

    <h3>💾 Save & Reload Demo</h3>

    <div class="row">
        <input type="text" id="nameInput" placeholder="Enter name...">
        <button onclick="saveItem()">Save</button>
        <button onclick="loadItems()">Reload</button>
        <button class="danger" onclick="clearAll()">Clear</button>
    </div>

    <div id="output"></div>

    <script>
        const KEY = 'my_data';

        /* ---- Save ---- */
        function saveItem() {
            const name = document.getElementById('nameInput').value.trim();
            if (!name) {
                alert('Please enter a name.');
                return;
            }
            let list = load();
            list.push({ name: name, time: Date.now() });
            persist(list);
            render(list);
            document.getElementById('nameInput').value = '';
        }

        /* ---- Delete one item ---- */
        function removeItem(index) {
            const list = load();
            list.splice(index, 1);
            persist(list);
            render(list);
        }

        /* ---- Clear all ---- */
        function clearAll() {
            if (!confirm('Delete all saved items?')) return;
            localStorage.removeItem(KEY);
            render([]);
        }

        /* ---- Storage helpers ---- */
        function load() {
            try {
                return JSON.parse(localStorage.getItem(KEY)) || [];
            } catch (e) {
                console.error('Load failed:', e);
                return [];
            }
        }

        function persist(list) {
            try {
                localStorage.setItem(KEY, JSON.stringify(list));
            } catch (e) {
                console.error('Save failed (quota?):', e);
                alert('Could not save. Storage may be full.');
            }
        }

        /* ---- Render ---- */
        function render(list) {
            const out = document.getElementById('output');
            if (!list.length) {
                out.innerHTML = '<p style="color:#888;">No items saved yet.</p>';
                return;
            }
            out.innerHTML = list.map((x, i) => `
                <div class="item">
                    <span>${i + 1}. ${escapeHtml(x.name)}</span>
                    <span>
                        <span class="time">${new Date(x.time).toLocaleTimeString()}</span>
                        <button class="danger" onclick="removeItem(${i})">×</button>
                    </span>
                </div>`).join('');
        }

        /* ---- XSS guard ---- */
        function escapeHtml(s) {
            return String(s)
                .replace(/&/g, '&amp;')
                .replace(/</g, '&lt;')
                .replace(/>/g, '&gt;')
                .replace(/"/g, '&quot;');
        }

        /* ---- Auto-load on page open ---- */
        window.onload = function() {
            render(load());
        };
    </script>
</body>
</html>
✅ Key points:
  • alert(), confirm(), prompt() work — no custom modal needed.
  • Wrap localStorage calls in try/catch to handle quota errors gracefully.
  • Call render(load()) inside window.onload so data reloads every time the page opens.
  • Use a unique key like 'my_data' per page to avoid clashes with other pages.
  • Always escape user input before injecting it into innerHTML (XSS guard).
