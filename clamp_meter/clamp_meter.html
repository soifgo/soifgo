ℹ️ Info

  • This app is designed for and compatible with SoifGo.
  • The calibration factor of each mode is set for 1 A. If your reading differs, adjust it.
  • Never use the phone to measure bare copper busbars or any uninsulated live parts.
  • Single wire and paired wire (two-core cable) each have their own calibration factor. Use the - SINGLE / = PAIR button to select the wire type (- = one wire, = = two wires); all four factors are saved.
  • In PAIR mode (two-core cable) the two currents flow in opposite directions, so their magnetic fields largely cancel each other. The field is reduced so much that the calibration factor becomes up to 10× smaller.
  • Keep the distance between the phone and the conductor the same for every measurement, otherwise the calculated value will not be correct.
