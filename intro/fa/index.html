ساخت کنترلر اندروید برای آردوینو و ESP32، فقط با HTML و جاوااسکریپت

SoifGo یک پلتفرم رایگان اندروید است که بدون نوشتن کد native اندروید، کنترلر، داشبورد و ابزار سخت‌افزاری سفارشی می‌سازید.

SoifGo چیست؟

اگر پروژه‌ای با آردوینو، ESP32، ESP8266 یا Raspberry Pi دارید و می‌خواهید از روی گوشی کنترلش کنید، معمولاً باید برنامه‌نویسی native اندروید یاد بگیرید. SoifGo این مرحله را حذف می‌کند: شما ظاهر برنامه را با HTML، CSS و جاوااسکریپت می‌نویسید و SoifGo ارتباط با بلوتوث، MQTT، سنسورهای گوشی و بقیه‌ی موارد را فراهم می‌کند.

یعنی اگر می‌توانید یک صفحه‌ی وب بنویسید، می‌توانید یک کنترلر سخت‌افزاری هم بسازید. و چون می‌توانید توضیح ایده‌تان را به یک دستیار هوش مصنوعی بدهید و کد HTML بگیرید، حتی نیازی نیست خودتان همه‌ی کد را بنویسید.

قابلیت‌ها

🔵 بلوتوث سریال

ارسال و دریافت متن با HC-05، HC-06، JDY-31، آردوینو، ESP32 و Raspberry Pi.

🟣 کلاینت MQTT

اتصال به هر بروکر (tcp یا ssl)، publish و subscribe و بررسی وضعیت اتصال.

🟠 HTTP API

ارسال JSON به هر آدرس و دریافت و استخراج مقدار از پاسخ.

🟢 سنسورهای گوشی

نور محیط، حرکت (شتاب‌سنج) و مغناطیس‌سنج به‌صورت زنده.

🎤 میکروفون و تشخیص گفتار

تبدیل گفتار به متن و ارسال آن به میکروکنترلر، مثلاً برای کنترل صوتی.

💾 ذخیره‌سازی محلی

نگه‌داری داده‌ها با localStorage حتی بعد از بستن برنامه.

🌐 WebView کامل

موتور مرورگر مدرن: Canvas، SVG، WebGL و کتابخانه‌هایی مثل Chart.js، D3 و Three.js.

🧩 حالت کلاسیک

دکمه و اسلایدر آماده، بدون هیچ کدی، برای کنترل‌های ساده.

چه چیزهایی می‌توان ساخت؟

  • کنترل LED، موتور و رله با بلوتوث
  • پنل کنترل ربات با نمایش وضعیت لحظه‌ای
  • داشبورد زنده‌ی سنسورها با نمودار
  • پل ارتباطی بلوتوث به MQTT
  • کنترل صوتی دستگاه‌ها با گفتار
  • پنل‌های IoT و ابزارهای نمونه‌سازی سریع

سؤالات متداول

آیا SoifGo رایگان است؟

بله. رایگان است و تبلیغات و خرید درون‌برنامه‌ای ندارد.

آیا بدون اینترنت کار می‌کند؟

بلوتوث و سنسورهای گوشی بدون اینترنت کار می‌کنند. فقط MQTT و HTTP به اینترنت یا شبکه نیاز دارند.

با چه سخت‌افزاری سازگار است؟

هر دستگاهی که از بلوتوث SPP (مثل HC-05 و HC-06)، MQTT یا HTTP REST استفاده کند؛ از جمله آردوینو، ESP32، ESP8266 و Raspberry Pi.

برای شروع به چه چیزی نیاز دارم؟

دانش پایه‌ی HTML کافی است و برای کارهای ساده حتی کد هم لازم نیست. آموزش‌ها، نمونه‌های آماده و کد آردوینوی آن‌ها در صفحه‌ی اصلی موجودند.
