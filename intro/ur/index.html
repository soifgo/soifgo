ویب صفحے پر جو کچھ ممکن ہے، SoifGo میں بھی ممکن ہے۔ SoifGo آپ کے ٹولز کو HTML میں چلاتا ہے اور فولڈرز میں محفوظ کرتا ہے۔ کیلکولیٹر اور سمیولیٹر سے لے کر تعلیمی ٹول اور ڈیش بورڈ تک، اور اگر ضروری ہو تو، Bluetooth اور MQTT کے ذریعے ہارڈویئر کنٹرول۔

Arduino اور ESP32 کنٹرول کریں Bluetooth اور MQTT سے اینڈرائیڈ فون سے

کوئی بھی آلہ جو Bluetooth SPP (جیسے HC-05 اور HC-06)، MQTT یا HTTP REST استعمال کرتا ہے، SoifGo کے ساتھ کام کرتا ہے: Arduino، ESP32، ESP8266 اور Raspberry Pi۔

Bluetooth سے LED، موٹر اور ریلے کے احکامات بھیجیں، Bluetooth سے MQTT کا پل بنائیں، یا سینسرز کے لیے لائیو ڈیش بورڈ بنائیں — سب کچھ HTML میں، نیٹو کوڈ کے بغیر۔

فولڈر اور صفحہ آرکائیو

SoifGo آپ کو فولڈرز اور صفحات دیتا ہے تاکہ آپ اپنے کام کو منظم طریقے سے محفوظ کر سکیں۔ ہر صفحے پر آپ کے پاس 40 بٹن اور 10 سلائیڈرز ہیں، اور ہر بٹن کو مقرر کردہ رویوں کے لیے ترتیب دیا جا سکتا ہے، بشمول فولڈرز اور صفحات کے درمیان نیویگیشن۔ اس طرح آپ بہت سے مینو بنا سکتے ہیں۔

بٹنوں کا ڈیزائن تیار ہے: رنگ، آئیکن، نام، فونٹ، آواز اور وائبریشن۔ ڈریگ اینڈ ڈراپ سے منتقل بھی کیے جا سکتے ہیں۔ ہر بٹن میں بھیجنے اور وصول کرنے جیسے بنیادی رویے ہو سکتے ہیں۔

ویب رویہ، آن لائن اور آف لائن دونوں

«ویب رویہ» (WebView) آپ کے آئیڈیاز کو زیادہ سے زیادہ صلاحیت کے ساتھ HTML میں حقیقت میں بدلنے میں مدد کرتا ہے، چاہے آن لائن ہو یا آف لائن۔ بس AI اسسٹنٹ کو اپنی ضرورت بتائیں اور HTML کوڈ مانگیں۔ پھر آپ کے پاس دو راستے ہیں:

  • فائل ڈاؤن لوڈ کریں اور SoifGo میں آف لائن ویب رویے سے لوڈ (ری لوڈ) کریں۔
  • یا کوڈ کاپی کریں اور SoifGo کے HTML ایڈیٹر میں پیسٹ کریں۔

دونوں طریقے کام کرتے ہیں اور آپ کی ویب ایپ SoifGo فولڈر میں محفوظ ہو جاتی ہے۔ چاہے کیلکولیٹر ہو، Bluetooth کنٹرولر ہو، IoT مانیٹرنگ ہو یا کچھ اور۔

فی صفحہ 40 مختلف ویب ایپس

ہر صفحے پر آپ کے پاس 40 مختلف ویب ایپس ہو سکتی ہیں۔ ہر بار AI اسسٹنٹ سے مانگنے کی ضرورت نہیں، اور آف لائن بھی استعمال کر سکتے ہیں۔ یہاں تک کہ ساتھیوں اور دوستوں کو بھیج سکتے ہیں تاکہ ڈاؤن لوڈ کر کے چلائیں۔

جدید براؤزر انجن: Canvas، SVG، WebGL اور Chart.js، D3 اور Three.js جیسی لائبریریاں گراف، سمیولیشن اور 3D ڈسپلے کے لیے۔

🧩 کلاسک موڈ

تیار بٹن اور سلائیڈرز، بغیر کوڈ کے، سادہ کنٹرولز اور مینو کے لیے۔

💾 لوکل اسٹوریج

localStorage سے ڈیٹا محفوظ کریں، ایپ بند کرنے کے بعد بھی رہے۔

🟢 فون سینسرز

محیطی روشنی، حرکت (ایکسلیرومیٹر) اور میگنیٹومیٹر ریئل ٹائم میں۔

🎤 مائیکروفون اور تقریر کی شناخت

آواز کو متن میں بدلیں اور اپنے ٹولز میں استعمال کریں یا آلات کو بھیجیں۔

🔵 سیریل Bluetooth

HC-05، HC-06، JDY-31، Arduino، ESP32 اور Raspberry Pi کے ساتھ متن بھیجیں اور وصول کریں۔

🟣 MQTT کلائنٹ

کسی بھی بروکر (tcp یا ssl) سے جڑیں، publish اور subscribe اور کنکشن کی حالت چیک کریں۔

🟠 HTTP API

کسی بھی پتے پر JSON بھیجیں اور جواب سے قیمت وصول اور نکالیں۔

اکثر پوچھے جانے والے سوالات

کیا SoifGo صرف Arduino اور الیکٹرانکس کے لیے ہے؟

نہیں۔ ہارڈویئر کنکشن صرف ایک خصوصیت ہے۔ چونکہ ٹولز HTML میں بنے ہیں، ویب صفحے پر جو کچھ ممکن ہے — حساب، گراف، نقلیں اور تعلیمی ٹولز — وہ SoifGo میں بھی ممکن ہے۔

کیا SoifGo مفت ہے؟

ہاں۔ مکمل طور پر مفت، اشتہارات اور ایپ کے اندر خریداری کے بغیر۔

کیا یہ انٹرنیٹ کے بغیر کام کرتا ہے؟

HTML ٹولز، Bluetooth اور فون سینسرز انٹرنیٹ کے بغیر کام کرتے ہیں۔ صرف MQTT اور HTTP کو نیٹ ورک کنکشن درکار ہے۔

SoifGo کس ہارڈویئر کے ساتھ مطابقت رکھتا ہے؟

کوئی بھی آلہ جو Bluetooth SPP (جیسے HC-05 اور HC-06)، MQTT یا HTTP REST استعمال کرتا ہے، بشمول Arduino، ESP32، ESP8266 اور Raspberry Pi۔

شروع کرنے کے لیے کیا درکار ہے؟

بنیادی HTML علم کافی ہے۔ اس کے بغیر بھی، آپ AI اسسٹنٹ کو اپنی ضرورت بتا کر HTML کوڈ حاصل کر سکتے ہیں۔ ٹیوٹوریلز اور تیار مثالیں مرکزی صفحے پر دستیاب ہیں۔

شروع کرنے کے لیے تیار ہیں؟

مرکزی صفحہ ڈاؤن لوڈ، ٹیوٹوریلز اور دستاویزات کے ساتھ کھلتا ہے، اور اردو ترجمہ خودکار طور پر فعال ہو جاتا ہے۔
