هەر ئامرازێک دەتەوێت بە HTML دروست بکە و لەسەر ئەندروید کاری پێ بکە

پڕۆگرامی SoifGo بەرنامەیەکی خۆڕایی ئەندرویدە بۆ دروستکردن و پاشکەوتکردنی ئامرازی تایبەت: ژمێرەر، شبیه‌ساز، ئامرازی فێرکاری، داشبۆرد و کۆنترۆڵری ڕەقامەواڵە، بەبێ پێویستی بە کۆدنووسی سەرەتایی (native) ئەندروید.

SoifGo؛ بەرنامەیەکی خێرا و بەکەڵکی ئەندروید، بۆ کێیە؟

لە ئێستادا، زۆربەی پێداویستییەکان—لە ژمێریاری و شبیه‌سازەوە تا دەگاتە داشبۆرد و پلەی کۆنترۆڵی تایبەت—دەکرێت جێبەجێ ببن. با کەمێک تیشک بخەینە سەر تایبەتمەندییەکانی SoifGo.

SoifGo ئامرازەکانت لە فۆرماتی HTML دا دەخاتە کار و لە بوخچەکاندا پاشکەوتیان دەکات. وەک چۆن لە لاپەڕەکانی وێبدا هەموو شتێک دەکرێت، مەودای سوودوەرگرتن لە SoifGo زۆر فراوانە: لە ژمێرەر و شبیه‌سازەوە تا دەگاتە ئامرازی فێرکاری، داشبۆرد و لە حاڵەتی پێویستدا کۆنترۆڵی ئامێرەکان بە بلوتوس و MQTT. ئەگەر دەتوانیت پەڕەیەکی وێب بنووسیت، یان داوا لە یاریدەدەری زیرەکی دەستکرد (AI) بکەیت، ئەوا دەتوانیت ئامرازی خۆت دروست بکەیت.

SoifGo بۆ کێ دیزاین کراوە؟

📐 بیرکاریزان و قوتابیان

ژمێرەری تایبەتمەند، هێڵکاری و فەنکشن، شبیه‌ساز و ئامرازی چارەسەرکردنی کێشەکان کە بەپێی پێویستی خۆت دروست کراون.

🎓 مامۆستایان و ڕاهێنەران

ئامرازی کارلێکبەر بۆ پۆل، ڕاهێنان و تاقیکردنەوەکان. فایلەکە بنێرە بۆ قوتابیان و ڕاهێنراوان تا ڕاستەوخۆ کاری پێ بکەن.

🏗️ ئەندازیاران لە هەوار و بوارە جیاوازەکاندا

ژمێرەری ئەندازیاری، گۆڕینی یەکەکان و خشتەی ژمێریاری کە هەمیشە لە شوێنی کار و بەبێ ئینتەرنێت بەردەستن.

🔌 ئارەزومەندان و گەشەپێدەرانی ئەلکترۆنیات

پەلی کۆنترۆڵ و مۆدیۆڵی بلوتوس و MQTT بۆ ئاردیونۆ، ESP32، ESP8266 و ڕاسپێری پای.

💡 هەر کەسێک کە بیرۆکەیەکی هەیە

بیرۆکەکەت بە یاریدەدەری AI بڵێ، کۆدی HTML وەربگرە و لە SoifGo دا کاری پێ بکە.

بوخچە و بەڕێوەبردنی لاپەڕەکان

SoifGo بوخچە و لاپەڕەت پێشکەش دەکات بۆ ڕێکخستنی کارەکانت بە شێوازێکی جوان. لە هەر لاپەڕەیەکدا، ٤٠گم دوگمە (button) و ١٠ سڵایده‌ر (slider)ت هەن، و دەتوانیت هەموو دوگمەیەک بۆ هەڵسوکەوتی دیاریکراو ڕێک بخەیت، لەوانە گەڕان لەنێوان بوخچە و لاپەڕەکانی SoifGo دا بۆ دروستکردنی لیستی چەند ئاستی.

دوگمەکان دیزاینی ئامادەیان تێدایە: ڕەنگ، وێنۆکە، ناو، فۆنت، دەنگ، لەرزین (vibration) و پشتگیری ڕاکێشان و دابەزاندن (drag-and-drop). هەموو دوگمەیەک دەتوانێت ئەرکە سەرەتاییەکانی ناردن و وەرگرتن جێبەجێ بکات.

هەڵسوکەوتی وێب، لەسەر هێڵ و بێ هێڵ

"هەڵسوکەوتی وێب" (WebView) یارمەتیت دەکات بیرۆکە و پێداویستییەکانت بە زۆرترین نەرمونیانییەوە لە فۆرماتی HTML دا بەدەست بهێنیت، چ لەسەر هێڵ بیت یان نا. تەنها داواکارییەکەت بە یاریدەدەری AI بڵێ و کۆدی HTML داوا بکە. پاشان دوو ڕێگەت هەیە:

  • فایلەکە دابەزێنە و بە هەڵسوکەوتی وێبی بێ هێڵی SoifGo بارگاویکە بکەرەوە (re-load).
  • یان کۆدەکە کۆپی بکە و لە دەستکاری‌کەری ناوەکی (HTML Editor) SoifGo دا پەیستی بکە.

هەردوو ڕێگاکە کار دەکەن، و ئەپی وێبەکەت لە بوخچەی SoifGo دا پاشکەوت دەبێت؛ جا با ژمێرەر بێت، کۆنترۆڵری بلوتوس بێت، چاودێری ئینتەرنێتی شتەکان (IoT) بێت، یان هەر ئامرازێکی تری تایبەت.

٤٠ ئەپی وێبی جیاواز لە هەر لاپەڕەیەکدا

دەتوانیت ٤٠ ئەپی وێبی جیاوازت لە هەر لاپەڕەیەکدا هەبێت. پێویست ناکات چەندین جار داوا لە یاریدەدەری AI بکەیت، و دەتوانیت بەبێ ئینتەرنێت کاریان پێ بکەیت. تەنانەت دەتوانیت لەگەڵ هاوکاران، هاوڕێکان یان ڕاهێنراواندا هاوبەشیان پێ بکەیت تا دایانبەزێنن و کاریان پێ بکەن.

تایبەتمەندییەکان

🌐 WebViewـی تەواو

مۆدێرنترین بڕاوزر: Canvas و SVG و WebGL و کتێبخانەکانی وەکو Chart.js، D3 و Three.js بۆ هێڵکاری، شبیه‌ساز و پیشاندانی سێ دووری (3D).

🧩 دۆخی کلاسیک (Classic Mode)

دوگمە و سڵایدەری ئامادە بێ پێویستی بە هیچ کۆدێک بۆ کۆنترۆڵی ساکار و لیستی ئاسان.

💾 پاشکەوتی ناوخۆیی (LocalStorage)

پاراستنی داتاکان بە بەکارهێنانی localStorage تەنانەت دوای داخستنی بەرنامەکەش.

🟢 هەستوەرەکانی مۆبایل

ڕووناکی دەوروبەر، جووڵە (accelerometer)، و مەگنتۆمەتر بە شێوازی ڕاستەوخۆ و لایڤ.

🎤 مایکرۆفۆن و ناسینەوەی دەنگ

گۆڕینی دەنگ بۆ نووسین و بەکارهێنانی لە ئامرازەکانتدا یان ناردنی بۆ ئامێرەکان.

🔵 Bluetooth Serial

ناردن و وەرگرتنی دەق لەگەڵ HC-05، HC-06، JDY-31، Arduino، ESP32 و Raspberry Pi.

🟣 برۆکەری MQTT

پەیوەندیکردن بە هەر برۆکارێکەوە (tcp یان ssl)، بڵاوکردنەوە (publish) و بەشداری کردن (subscribe)، و چاودێری دۆخی پەیوەندییەکە.

🟠 HTTP API

ناردنی JSON بۆ هەر ناونیشانێک و وەرگرتن و دەرهێنانی بەهاکان لە وەڵامەکەدا.

چ شتێک دەکرێت دروست بکرێت؟

  • ژمێرەری تایبەتمەند و ئامرازی حیساباتی
  • هێڵکاری، شبیه‌ساز و بینینی داتا
  • ئامرازی فێرکاری کارلێکبەر، ڕاهێنان و تاقیکردنەوە
  • پێشکەشکردنی سێ دووری (3D) و ئامرازی زانستی
  • داشبۆرد و پەلی کۆنترۆڵی تایبەت بۆ کارەکەت
  • کۆنترۆڵکردنی گڵۆپ (LED)، مۆتۆر، ڕیلەی و ڕۆبۆتەکان بە بلوتوس و پردی بلوتوس بۆ MQTT
  • کۆنترۆڵی دەنگی ئامێرەکان بە قسەکردن

پرسیارە دووبارەبووەوەکان (FAQ)

ئایا SoifGo تەنها بۆ ئاردیونۆ و ئەلکترۆنیاتە؟

نەخێر. پەیوەندی بە ڕەقامەواڵەوە تەنها یەکێکە لە تایبەتمەندییەکان. لەبەر ئەوەی ئامرازەکان پشت بە HTML دەبەستن، هەر شتێک لە لاپەڕەی وێبدا بکرێت (وەکو حیسابات، هێڵکاری، شبیه‌ساز و ئامرازی فێرکاری) لە SoifGo شدا بە شێوازێکی کارا کار دەکات.

ئایا بەرنامەی SoifGo خۆڕاییە؟

بەڵێ، بە تەواوی خۆڕاییە و هیچ ڕیکلامێک یان کڕینی ناوخۆیی تێدا نییە.

ئایا بێ هێڵی ئینتەرنێت کار دەکات؟

ئامرازەکانی HTML، بلوتوس و هەستوەرەکانی مۆبایل بەبێ ئینتەرنێت کار دەکەن. تەنها MQTT و HTTP پێویستیان بە ئینتەرنێت یان هێڵی ناوخۆیی هەیە.

بۆ پەیوەندی بە ڕەقامەواڵەوە، چ سیستەمێک گونجاوە؟

هەر ئامێرێک کە پشتگیری Bluetooth SPP (وەکو HC-05 و HC-06)، MQTT یان HTTP REST بکات؛ لەوانە Arduino، ESP32، ESP8266 و Raspberry Pi.

بۆ دەستپێکردن چی پێویستە؟

شارەزاییەکی سەرەتایی لە HTML دا بەسە. تەنانەت بەبێ ئەوەش، دەتوانیت داوا لە یاریدەدەری AI بکەیت کۆدی HTML بۆ دروست بکات. ڕێنمایی و نموونەی ئامادە لە لاپەڕەی سەرەکیدا هەن.

چوونە ژوورەوە بۆ SoifGo ← لاپەڕەی سەرەکی لەگەڵ دابەزاندن، ڕێنمایی و دۆکیومێنتاریدا دەکرێتەوە، لەگەڵ چالاککردنی وەرگێڕانی کوردی ئۆتۆماتیکی.
