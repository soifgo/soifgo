SoifGo — 頭の中にあるあらゆるツールを HTML で作り、Android で実行

SoifGo は、カスタムツールを作成・保存できる無料の Android アプリです： 電卓、シミュレーター、教育ツール、ダッシュボード、さらにはハードウェアコントローラーまで、 ネイティブ Android コードを書かずに。

HTML で Android アプリを作成 — ネイティブコード不要

Web ページで可能なことはすべて、SoifGo でも可能です。 SoifGo はあなたのツールを HTML として実行し、フォルダに保存します。 電卓とシミュレーターから教育ツールとダッシュボードまで、 必要に応じて Bluetooth と MQTT によるハードウェア制御も。

Web ページを書けるなら、あるいは AI アシスタントに要望を伝えられるなら、 自分のツールを作ることができます。

Android スマホから Arduino と ESP32 を制御（Bluetooth と MQTT）

Bluetooth SPP（HC-05 や HC-06 など）、 MQTT、または HTTP REST を使うあらゆるデバイスが SoifGo で動作します： Arduino、ESP32、ESP8266、Raspberry Pi。

Bluetooth で LED、モーター、リレーのコマンドを送信し、Bluetooth から MQTT へのブリッジを作り、 またはセンサーのライブダッシュボードを構築 — すべて HTML で、ネイティブコードなし。

フォルダとページのアーカイブ

SoifGo は、作業を整理して保存するためのフォルダとページを提供します。 各ページには40 個のボタンと10 個のスライダーがあり、各ボタンは 定義された動作に設定できます。フォルダとページ間のナビゲーションも含みます。 これにより多くのメニューを作成できます。

ボタンには既成のデザインがあります：色、アイコン、名前、フォント、サウンド、振動。 ドラッグ＆ドロップで移動できます。各ボタンは送信や受信などの基本的な動作を持てます。

Web 動作、オンラインでもオフラインでも

「Web 動作」（WebView）は、あなたのアイデアを最大限の機能で HTML として実現するのを助けます。 オンラインでもオフラインでも。AI アシスタントに要望を伝え、HTML コードを求めればいいだけです。その後、二つの道があります：

  • ファイルをダウンロードし、SoifGo のオフライン Web 動作で読み込む（リロード）。
  • またはコードをコピーして、SoifGo 内の HTML エディタに貼り付ける。

どちらの方法でも機能し、あなたの Web アプリは SoifGo のフォルダに保存されます。 電卓でも、Bluetooth コントローラーでも、IoT モニタリングでも、その他何でも。

1 ページに 40 個の異なる Web アプリ

1 ページに 40 個の異なる Web アプリを持つことができます。毎回 AI アシスタントに 頼む必要はなく、オフラインでも使えます。 同僚や友人に送ってダウンロードしてもらい、実行してもらうこともできます。

SoifGo の機能

🌐 完全な WebView

モダンなブラウザエンジン：Canvas、SVG、WebGL と Chart.js、D3、Three.js などのライブラリでグラフ、シミュレーション、3D 表示。

🧩 クラシックモード

既成のボタンとスライダー、コード不要、シンプルな制御とメニュー用。

💾 ローカルストレージ

localStorage でデータを保存、アプリを閉じても保持。

🟢 スマホのセンサー

環境光、モーション（加速度センサー）、磁気センサーをリアルタイムで。

🎤 マイクと音声認識

音声をテキストに変換し、ツールで使用したりデバイスに送信。

🔵 シリアル Bluetooth

HC-05、HC-06、JDY-31、Arduino、ESP32、Raspberry Pi とテキストを送受信。

🟣 MQTT クライアント

任意のブローカー（tcp または ssl）に接続、publish と subscribe、接続状態の確認。

🟠 HTTP API

任意のアドレスに JSON を送信し、レスポンスから値を受信・抽出。

よくある質問

SoifGo は Arduino と電子工作専用ですか？

いいえ。ハードウェア接続は機能の一つにすぎません。ツールは HTML で作られているため、Web ページで可能なこと — 計算、グラフ、シミュレーション、教育ツール — はすべて SoifGo でも可能です。

SoifGo は無料ですか？

はい。完全無料で、広告やアプリ内課金はありません。

インターネットなしで動作しますか？

HTML ツール、Bluetooth、スマホのセンサーはインターネットなしで動作します。MQTT と HTTP のみネットワーク接続が必要です。

どのハードウェアと互換性がありますか？

Bluetooth SPP（HC-05、HC-06 など）、MQTT、または HTTP REST を使用するすべてのデバイス。Arduino、ESP32、ESP8266、Raspberry Pi を含みます。

始めるには何が必要ですか？

基本的な HTML の知識で十分です。なくても、AI アシスタントに要望を伝えて HTML コードを取得できます。チュートリアルと既成のサンプルはメインページにあります。

始める準備はできましたか？

メインページがダウンロード、チュートリアル、ドキュメントとともに開き、日本語翻訳が自動で有効になります。
