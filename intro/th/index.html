สร้างเครื่องมือใดๆ ที่คุณจินตนาการด้วย HTML และรันบน Android

SoifGo เป็นแอปพลิเคชัน Android ฟรีสำหรับสร้างและจัดเก็บเครื่องมือแบบกำหนดเอง เช่น เครื่องคิดเลข โปรแกรมจำลอง เครื่องมือการศึกษา แดชบอร์ด และตัวควบคุมฮาร์ดแวร์ โดยไม่ต้องมีความรู้เกี่ยวกับการเขียนโปรแกรม Android แบบเนทีฟ

SoifGo; แอปพลิเคชัน Android ที่รวดเร็วและมีประสิทธิภาพ เหมาะสำหรับใคร?

ทุกวันนี้ ความต้องการส่วนใหญ่ ตั้งแต่การคำนวณและการจำลอง ไปจนถึงแดชบอร์ดและแผงควบคุมแบบกำหนดเอง สามารถใช้งานได้อย่างง่ายดาย มาดูจุดแข็งของ SoifGo กันดีกว่า

SoifGo รันเครื่องมือของคุณในรูปแบบ HTML และจัดระเบียบเป็นโฟลเดอร์ เนื่องจาก HTML รองรับทุกสิ่งที่เป็นไปได้บนหน้าเว็บ ขอบเขตการใช้งานจึงกว้างมาก ตั้งแต่เครื่องคิดเลขและการจำลอง ไปจนถึงเครื่องมือการเรียนรู้ แดชบอร์ด และการควบคุมฮาร์ดแวร์ผ่าน Bluetooth และ MQTT หากคุณรู้วิธีเขียนหน้าเว็บหรืออธิบายความต้องการของคุณให้ผู้ช่วย AI ฟัง คุณก็สามารถสร้างเครื่องมือของคุณเองได้

SoifGo ออกแบบมาสำหรับใคร?

📐 นักคณิตศาสตร์และนักเรียน

เครื่องคิดเลขเฉพาะทาง กราฟและฟังก์ชัน การจำลอง และเครื่องมือแก้ปัญหาที่ปรับแต่งตามความต้องการของคุณ

🎓 ครูและผู้ฝึกสอน

เครื่องมือแบบโต้ตอบสำหรับห้องเรียน แบบฝึกหัด และแบบทดสอบ ส่งไฟล์ให้ให้นักเรียนหรือผู้ฝึกอบรมเพื่อรันได้โดยตรง

🏗️ วิศวกรทุกสาขา

เครื่องคำนวณทางวิศวกรรม ตัวแปลงหน่วย และสเปรดชีตส่วนตัวที่พร้อมใช้งานเสมอในการทำงานและแบบออฟไลน์

🔌 ผู้ที่ชื่นชอบงานอดิเรกและนักพัฒนาอิเล็กทรอนิกส์

แผงควบคุมและโมดูล Bluetooth และ MQTT สำหรับ Arduino, ESP32, ESP8266 และ Raspberry Pi

💡 ทุกคนที่มีไอเดีย

แบ่งปันไอเดียของคุณกับผู้ช่วย AI รับโค้ด HTML แล้วรันใน SoifGo

การจัดการโฟลเดอร์และหน้า

SoifGo มีโฟลเดอร์และหน้าเพื่อให้คุณจัดระเบียบงานได้อย่างเป็นระเบียบ ในแต่ละหน้าคุณจะมี ปุ่ม 40 ปุ่ม (buttons) และ แถบเลื่อน 10 แถบ (sliders) และคุณสามารถกำหนดค่าแต่ละปุ่มสำหรับพฤติกรรมเฉพาะได้ ซึ่งรวมถึงการนำทางระหว่างโฟลเดอร์และหน้าของ SoifGo เพื่อสร้างเมนูหลายระดับ

ปุ่มต่างๆ มีตัวเลือกการออกแบบที่กำหนดไว้ล่วงหน้า: สี ไอคอน ชื่อ แบบอักษร เสียง การสั่น และการรองรับการลากและวาง (drag-and-drop) แต่ละปุ่มสามารถทำงานอินพุตและเอาต์พุตพื้นฐานได้

พฤติกรรมเว็บ ออนไลน์และออฟไลน์

"พฤติกรรมเว็บ" (WebView) ช่วยให้คุณตระหนักถึงไอเดียและความต้องการของคุณด้วยความยืดหยุ่นสูงสุดในรูปแบบ HTML ไม่ว่าคุณจะออนไลน์หรือออฟไลน์ เพียงแค่บอกความต้องการของคุณกับผู้ช่วย AI และขอโค้ด HTML จากนั้นคุณมีสองทางเลือก:

  • ดาวน์โหลดไฟล์และโหลด (โหลดซ้ำ) โดยใช้พฤติกรรมเว็บแบบออฟไลน์ใน SoifGo
  • หรือคัดลอกโค้ดและวางลงในตัวแก้ไข HTML ในตัวของ SoifGo

ทั้งสองวิธีใช้งานได้ และเว็บแอปของคุณจะถูกจัดเก็บไว้ในโฟลเดอร์ SoifGo ไม่ว่าจะเป็นเครื่องคิดเลข ตัวควบคุม Bluetooth การตรวจสอบ IoT หรือเครื่องมือแบบกำหนดเองอื่นๆ

เว็บแอปที่แตกต่างกันถึง 40 แอปในแต่ละหน้า

คุณสามารถมีเว็บแอปที่แตกต่างกันได้สูงสุด 40 แอปในแต่ละหน้า คุณไม่ต้องขอผู้ช่วย AI ซ้ำๆ และสามารถทำงานร่วมกับแอปเหล่านี้แบบออฟไลน์ได้ คุณยังสามารถแชร์ให้กับเพื่อนร่วมงาน เพื่อน หรือผู้ฝึกอบรมเพื่อให้พวกเขานำไปดาวน์โหลดและรันได้

คุณสมบัติ

🌐 WebView เต็มรูปแบบ

เอนจินเบราว์เซอร์ที่ทันสมัย: Canvas, SVG, WebGL และไลบรารีเช่น Chart.js, D3 และ Three.js สำหรับกราฟ การจำลอง และการแสดงภาพ 3 มิติ

🧩 โหมดคลาสสิก (Classic Mode)

ปุ่มและแถบเลื่อนที่พร้อมใช้งานโดยไม่ต้องใช้โค้ดใดๆ สำหรับการควบคุมง่ายๆ และเมนูด่วน

💾 ที่เก็บข้อมูลภายใน (LocalStorage)

การคงอยู่ของข้อมูลโดยใช้ localStorage แม้หลังจากปิดแอปพลิเคชัน

🟢 เซ็นเซอร์โทรศัพท์

แสงโดยรอบ การเคลื่อนไหว (มาตรความเร่ง) และสนามแม่เหล็กแบบสดและเรียลไทม์

🎤 ไมโครโฟนและการรู้จำเสียงพูด

แปลงเสียงพูดเป็นข้อความเพื่อใช้ในเครื่องมือของคุณหรือส่งไปยังอุปกรณ์

🔵 Bluetooth Serial

การส่งและรับข้อความด้วย HC-05, HC-06, JDY-31, Arduino, ESP32 และ Raspberry Pi

🟣 MQTT Client

การเชื่อมต่อกับโบรกเกอร์ใดๆ (tcp หรือ ssl) การเผยแพร่และการสมัครสมาชิก (publish & subscribe) และการตรวจสอบสถานะการเชื่อมต่อ

🟠 HTTP API

การส่ง JSON ไปยังที่อยู่ใดๆ การรับและการดึงค่าจากผลลัพธ์ (response)

สามารถสร้างอะไรได้บ้าง?

  • เครื่องคิดเลขพิเศษและเครื่องมือคำนวณ
  • กราฟ การจำลอง และการแสดงภาพข้อมูล
  • เครื่องมือการศึกษาแบบโต้ตอบ แบบฝึกหัด และแบบทดสอบ
  • การนำเสนอ 3 มิติและเครื่องมือทางวิทยาศาสตร์
  • แดชบอร์ดและแผงควบคุมแบบกำหนดเองสำหรับการทำงานของคุณ
  • การควบคุมไฟ (LED) มอเตอร์ รีเลย์ และหุ่นยนต์ผ่าน Bluetooth และสะพานเชื่อม Bluetooth สู่ MQTT
  • การควบคุมอุปกรณ์ด้วยเสียงผ่านคำสั่งเสียง

คำถามที่พบบ่อย (FAQ)

SoifGo สำหรับ Arduino และอุปกรณ์อิเล็กทรอนิกส์เท่านั้นใช่หรือไม่?

ไม่ใช่ การเชื่อมต่อฮาร์ดแวร์เป็นเพียงหนึ่งในคุณสมบัติเท่านั้น เนื่องจากเครื่องมืออิงตาม HTML ทุกสิ่งที่เป็นไปได้บนหน้าเว็บ (เช่น การคำนวณ กราฟ การจำลอง และเครื่องมือการศึกษา) จึงทำงานได้อย่างราบรื่นใน SoifGo เช่นกัน

แอป SoifGo ฟรีหรือไม่?

ใช่ ฟรีทั้งหมด ไม่มีโฆษณาหรือการซื้อภายในแอป

ทำงานแบบออฟไลน์ได้หรือไม่?

เครื่องมือ HTML, Bluetooth และเซ็นเซอร์โทรศัพท์ทำงานแบบออฟไลน์ มีเพียง MQTT และ HTTP เท่านั้นที่ต้องเชื่อมต่ออินเทอร์เน็ตหรือเครือข่ายท้องถิ่น

ระบบใดบ้างที่ใช้งานร่วมกับการเชื่อมต่อฮาร์ดแวร์ได้?

อุปกรณ์ใดๆ ที่รองรับ Bluetooth SPP (เช่น HC-05 และ HC-06), MQTT หรือ HTTP REST รวมถึง Arduino, ESP32, ESP8266 และ Raspberry Pi

ต้องใช้อะไรบ้างในการเริ่มต้น?

ความรู้พื้นฐานเกี่ยวกับ HTML ก็เพียงพอแล้ว แม้จะไม่มีความรู้ คุณก็สามารถขอโค้ด HTML จากผู้ช่วย AI ได้ หน้าแรกมีบทช่วยสอนและตัวอย่างพร้อมใช้งาน
