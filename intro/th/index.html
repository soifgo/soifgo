SoifGo — สร้างเครื่องมือในจินตนาการของคุณด้วย HTML และรันบน Android

SoifGo เป็นแอป Android ฟรีสำหรับสร้างและเก็บเครื่องมือของคุณเอง: เครื่องคิดเลข ตัวจำลอง เครื่องมือการศึกษา แดชบอร์ด และแม้แต่ตัวควบคุมฮาร์ดแวร์ โดยไม่ต้องเขียนโค้ด Android เนทีฟ

สร้างแอป Android ด้วย HTML — โดยไม่ต้องใช้โค้ดเนทีฟ

ทุกสิ่งที่ทำได้ในหน้าเว็บก็ทำได้ใน SoifGo SoifGo รันเครื่องมือของคุณเป็น HTML และเก็บไว้ในโฟลเดอร์ ตั้งแต่เครื่องคิดเลขและตัวจำลอง ไปจนถึงเครื่องมือการศึกษาและแดชบอร์ด และหากจำเป็น ก็ควบคุมฮาร์ดแวร์ผ่าน Bluetooth และ MQTT

ถ้าคุณเขียนหน้าเว็บได้ หรืออธิบายความต้องการให้ผู้ช่วย AI ได้ คุณก็สร้างเครื่องมือของคุณเองได้

SoifGo เหมาะกับใคร?

📐 นักคณิตศาสตร์และนักศึกษา

เครื่องคิดเลขเฉพาะทาง กราฟและฟังก์ชัน การจำลอง และเครื่องมือแก้ปัญหา ตรงตามความต้องการของคุณ

🎓 ครูและผู้ฝึกสอน

เครื่องมือแบบโต้ตอบสำหรับห้องเรียน แบบฝึกหัด และการสอบ ส่งไฟล์ให้นักเรียนรันเองได้

🏗️ วิศวกรทุกสาขา

เครื่องคิดเลขวิศวกรรม การแปลงหน่วย และตารางคำนวณส่วนตัว ใช้ได้ที่ทำงานและออฟไลน์

🔌 เมกเกอร์และช่างอิเล็กทรอนิกส์

ตัวควบคุมและแดชบอร์ด Bluetooth และ MQTT สำหรับ Arduino, ESP32, ESP8266 และ Raspberry Pi

ควบคุม Arduino และ ESP32 ผ่าน Bluetooth และ MQTT จากมือถือ Android

อุปกรณ์ใดก็ตามที่ใช้ Bluetooth SPP (เช่น HC-05 และ HC-06), MQTT หรือ HTTP REST ทำงานร่วมกับ SoifGo: Arduino, ESP32, ESP8266 และ Raspberry Pi

ส่งคำสั่ง LED มอเตอร์ และรีเลย์ผ่าน Bluetooth สร้างสะพาน Bluetooth ไป MQTT หรือสร้างแดชบอร์ดสดสำหรับเซ็นเซอร์ — ทั้งหมดด้วย HTML โดยไม่ต้องใช้โค้ดเนทีฟ

เก็บถาวรโฟลเดอร์และหน้า

SoifGo ให้โฟลเดอร์และหน้าเพื่อเก็บงานของคุณอย่างเป็นระเบียบ ในแต่ละหน้าคุณมี 40 ปุ่ม และ 10 สไลเดอร์ และแต่ละปุ่ม สามารถตั้งค่าสำหรับพฤติกรรมที่กำหนด รวมถึงการนำทางระหว่างโฟลเดอร์และหน้า ด้วยวิธีนี้คุณสามารถสร้างเมนูมากมายได้

ปุ่มมีดีไซน์พร้อมใช้: สี ไอคอน ชื่อ ฟอนต์ เสียง และการสั่น ยังสามารถย้ายด้วยการลากและวางได้ แต่ละปุ่มสามารถมีพฤติกรรมพื้นฐานเช่นส่งและรับได้

พฤติกรรมเว็บ ทั้งออนไลน์และออฟไลน์

«พฤติกรรมเว็บ» (WebView) ช่วยให้คุณทำไอเดียให้เป็นจริงด้วยความสามารถสูงสุดและในรูปแบบ HTML ทั้งออนไลน์และออฟไลน์ เพียงอธิบายความต้องการให้ผู้ช่วย AI และขอโค้ด HTML จากนั้นคุณมีสองทาง:

  • ดาวน์โหลดไฟล์และโหลด (รีโหลด) ด้วยพฤติกรรมเว็บออฟไลน์ใน SoifGo
  • หรือคัดลอกโค้ดและวางในตัวแก้ไข HTML ภายใน SoifGo

ทั้งสองวิธีใช้ได้ และเว็บแอปของคุณจะถูกเก็บในโฟลเดอร์ SoifGo ไม่ว่าจะเป็นเครื่องคิดเลข ตัวควบคุม Bluetooth การตรวจสอบ IoT หรืออะไรก็ตาม

40 เว็บแอปที่แตกต่างกันในแต่ละหน้า

คุณสามารถมี 40 เว็บแอปที่แตกต่างกันในแต่ละหน้า ไม่ต้องขอจาก ผู้ช่วย AI ทุกครั้ง และสามารถใช้งานได้แบบออฟไลน์ ยังส่งให้เพื่อนร่วมงานและเพื่อน ๆ ดาวน์โหลดและรันได้อีกด้วย

คุณสมบัติของ SoifGo

🌐 WebView แบบเต็ม

เอนจินเบราว์เซอร์สมัยใหม่: Canvas, SVG, WebGL และไลบรารีเช่น Chart.js, D3 และ Three.js สำหรับกราฟ การจำลอง และการแสดงผล 3D

🧩 โหมดคลาสสิก

ปุ่มและสไลเดอร์พร้อมใช้ ไม่ต้องเขียนโค้ด สำหรับการควบคุมและเมนูง่าย ๆ

💾 ที่เก็บข้อมูลในเครื่อง

เก็บข้อมูลด้วย localStorage แม้หลังปิดแอป

🟢 เซ็นเซอร์มือถือ

แสงโดยรอบ การเคลื่อนไหว (มาตรวัดความเร่ง) และแมกนีโตมิเตอร์แบบเรียลไทม์

🎤 ไมโครโฟนและการรู้จำเสียง

แปลงเสียงเป็นข้อความและใช้ในเครื่องมือของคุณหรือส่งไปยังอุปกรณ์

🔵 Bluetooth แบบอนุกรม

ส่งและรับข้อความกับ HC-05, HC-06, JDY-31, Arduino, ESP32 และ Raspberry Pi

🟣 ไคลเอนต์ MQTT

เชื่อมต่อกับโบรกเกอร์ใดก็ได้ (tcp หรือ ssl), publish และ subscribe และตรวจสอบสถานะ

🟠 HTTP API

ส่ง JSON ไปยังที่อยู่ใดก็ได้ และรับและดึงค่าจากการตอบกลับ

สร้างอะไรได้บ้าง?

  • เครื่องคิดเลขและเครื่องมือคำนวณเฉพาะทาง
  • กราฟ การจำลอง และการแสดงข้อมูล
  • เครื่องมือการศึกษาแบบโต้ตอบ แบบฝึกหัด และการสอบ
  • การแสดงผล 3D และเครื่องมือวิทยาศาสตร์
  • แดชบอร์ดและแผงเฉพาะสำหรับงานของคุณ
  • ควบคุม LED มอเตอร์ รีเลย์ และหุ่นยนต์ผ่าน Bluetooth และสะพาน Bluetooth ไป MQTT
  • ควบคุมอุปกรณ์ด้วยเสียง

คำถามที่พบบ่อย

SoifGo ใช้กับ Arduino และอิเล็กทรอนิกส์เท่านั้นหรือไม่?

ไม่ใช่ การเชื่อมต่อฮาร์ดแวร์เป็นเพียงหนึ่งในคุณสมบัติ เนื่องจากเครื่องมือสร้างด้วย HTML ทุกสิ่งที่ทำได้ในหน้าเว็บ — การคำนวณ กราฟ การจำลอง และเครื่องมือการศึกษา — ก็ทำได้ใน SoifGo เช่นกัน

SoifGo ฟรีหรือไม่?

ใช่ ฟรีทั้งหมด ไม่มีโฆษณาและไม่มีการซื้อในแอป

ทำงานโดยไม่ต้องต่ออินเทอร์เน็ตหรือไม่?

เครื่องมือ HTML, Bluetooth และเซ็นเซอร์มือถือทำงานโดยไม่ต้องต่ออินเทอร์เน็ต มีเพียง MQTT และ HTTP เท่านั้นที่ต้องเชื่อมต่อเครือข่าย

SoifGo เข้ากันได้กับฮาร์ดแวร์ใด?

อุปกรณ์ใดก็ตามที่ใช้ Bluetooth SPP (เช่น HC-05 และ HC-06), MQTT หรือ HTTP REST รวมถึง Arduino, ESP32, ESP8266 และ Raspberry Pi

ต้องมีอะไรในการเริ่มต้น?

ความรู้ HTML เบื้องต้นก็เพียงพอ แม้ไม่มีก็สามารถอธิบายความต้องการให้ผู้ช่วย AI และรับโค้ด HTML ได้ บทแนะนำและตัวอย่างพร้อมใช้มีอยู่ในหน้าหลัก

พร้อมเริ่มต้นหรือยัง?

หน้าหลักเปิดพร้อมดาวน์โหลด บทแนะนำ และเอกสาร และการแปลภาษาไทยจะเปิดใช้งานโดยอัตโนมัติ
