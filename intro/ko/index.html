HTML로 원하는 도구를 직접 만들고 안드로이드에서 실행하세요

SoifGo는 네이티브 안드로이드 프로그래밍 지식 없이도 계산기, 시뮬레이터, 교육용 도구, 대시보드, 하드웨어 컨트롤러 등의 맞춤형 도구를 만들고 보관할 수 있는 무료 안드로이드 앱입니다.

SoifGo란 무엇이며 누구를 위한 앱인가요?

오늘날 계산 및 시뮬레이션부터 맞춤형 대시보드 및 제어판에 이르기까지 대부분의 요구 사항을 손쉽게 구현할 수 있습니다. SoifGo의 강점에 주목해 보세요.

SoifGo는 HTML 형식으로 도구를 실행하고 폴더별로 정리합니다. HTML은 웹페이지에서 가능한 모든 기능을 지원하므로 계산기와 시뮬레이션부터 학습 도구, 대시보드, 필요에 따라 블루투스 및 MQTT를 통한 하드웨어 제어까지 응용 범위가 매우 넓습니다. 웹페이지를 작성할 수 있거나 AI 어시스턴트에게 요구사항을 설명할 수 있다면 누구나 자신만의 도구를 구축할 수 있습니다.

SoifGo는 어떤 분들을 위해 설계되었나요?

📐 수학자 및 학생

요구사항에 맞게 맞춤화된 특수 계산기, 그래프 및 함수, 시뮬레이션, 문제 해결 도구.

🎓 교사 및 강사

수업용 대화형 도구, 연습 문제, 퀴즈. 파일을 학생이나 교육생에게 보내어 직접 실행하게 할 수 있습니다.

🏗️ 모든 분야의 엔지니어

업무 중이나 오프라인에서도 항상 사용할 수 있는 엔지니어링 계산기, 단위 변환기, 개인 스프레드시트.

🔌 취미 및 전자 개발자

Arduino, ESP32, ESP8266, Raspberry Pi를 위한 제어판, 블루투스 및 MQTT 모듈.

💡 아이디어가 있는 모든 분

AI 어시스턴트와 아이디어를 공유하고 HTML 코드를 얻어 SoifGo에서 실행하세요.

폴더 및 페이지 관리

SoifGo는 작업을 깔끔하게 정리할 수 있도록 폴더와 페이지 기능을 제공합니다. 각 페이지에는 40개의 버튼과 10개의 슬라이더가 있으며, 다단 메뉴를 만들기 위한 SoifGo 폴더 및 페이지 간 이동을 포함하여 특정 동작에 맞게 각 버튼을 설정할 수 있습니다.

버튼에는 색상, 아이콘, 이름, 글꼴, 사운드, 진동, 드래그앤드롭 지원 등 미리 정의된 디자인 옵션이 포함되어 있습니다. 각 버튼은 기본적인 입력 및 출력 작업을 수행할 수 있습니다.

웹 동작 (온라인 및 오프라인)

"웹 동작"(WebView)을 사용하면 온라인이든 오프라인이든 HTML 형식으로 최대의 유연성을 발휘하여 아이디어와 요구사항을 실현할 수 있습니다. AI 어시스턴트에게 요청사항을 전달하고 HTML 코드를 요청하기만 하면 됩니다. 이후 두 가지 방법 중 선택할 수 있습니다.

  • 파일을 다운로드하여 SoifGo의 오프라인 웹 동작 기능을 사용하여 로드(새로 고침)합니다.
  • 또는 코드를 복사하여 SoifGo에 내장된 HTML 편집기에 붙여넣습니다.

두 방법 모두 작동하며, 계산기, 블루투스 컨트롤러, IoT 모니터링 또는 기타 맞춤형 도구 등 웹 앱이 SoifGo 폴더에 안전하게 보관됩니다.

페이지당 최대 40개의 서로 다른 웹 앱

각 페이지마다 최대 40개의 서로 다른 웹 앱을 가질 수 있습니다. AI 어시스턴트에게 반복해서 물어볼 필요 없이 오프라인에서도 작업할 수 있으며, 동료, 친구, 교육생에게 공유하여 다운로드하고 실행하도록 할 수 있습니다.

주요 기능

🌐 완전한 WebView

최신 브라우저 엔진 탑재: 그래프, 시뮬레이션, 3D 시각화를 위한 Canvas, SVG, WebGL 및 Chart.js, D3, Three.js 같은 라이브러리 지원.

🧩 클래식 모드

간단한 제어와 빠른 메뉴를 위해 코드가 전혀 필요 없는 사전 준비된 버튼과 슬라이더.

💾 로컬 저장소 (LocalStorage)

앱을 종료한 후에도 localStorage를 사용하여 데이터 영구 유지.

🟢 스마트폰 센서

주위 조도, 움직임(가속도계), 자기장 센서를 라이브 및 실시간으로 활용.

🎤 마이크 및 음성 인식

음성을 텍스트로 변환하여 도구에서 사용하거나 장치로 전송.

🔵 블루투스 시리얼

HC-05, HC-06, JDY-31, Arduino, ESP32, Raspberry Pi와 텍스트 송수신.

🟣 MQTT 클라이언트

모든 브로커(tcp 또는 ssl) 연결, 발행 및 구독(publish & subscribe), 연결 상태 모니터링.

🟠 HTTP API

임의의 주소로 JSON 전송, 응답에서 값 수신 및 추출.

  • 상호작용형 교육 도구, 연습 문제, 퀴즈

  • 음성 명령을 통한 기기 음성 제어

자주 묻는 질문 (FAQ)

SoifGo는 아두이노와 전자기기 전용인가요?

아닙니다. 하드웨어 연결은 기능 중 일부일 뿐입니다. 도구가 HTML 기반이므로 웹페이지에서 가능한 모든 것(계산, 그래프, 시뮬레이션, 교육 도구 등)이 SoifGo에서도 원활하게 작동합니다.

SoifGo 앱은 무료인가요?

네, 광고나 인앱 결제 없이 완전히 무료입니다.

오프라인에서도 작동하나요?

HTML 도구, 블루투스, 스마트폰 센서는 오프라인에서 작동합니다. MQTT와 HTTP만 인터넷 또는 로컬 네트워크 연결이 필요합니다.

하드웨어 연결과 호환되는 시스템은 무엇인가요?

블루투스 SPP(HC-05, HC-06 등), MQTT, HTTP REST를 지원하는 모든 기기(Arduino, ESP32, ESP8266, Raspberry Pi 포함)와 호환됩니다.

시작하려면 무엇이 필요한가요?

기본적인 HTML 지식이면 충분합니다. 지식이 없더라도 AI 어시스턴트에세 HTML 코드를 요청하면 됩니다. 홈페이지에 튜토리얼과 준비된 예제가 있습니다.

SoifGo로 이동 ← 홈페이지는 다운로드, 튜토리얼, 문서와 함께 열리며 한국어 자동 번역이 활성화됩니다.
