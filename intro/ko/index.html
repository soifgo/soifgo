SoifGo — 머릿속에 있는 모든 도구를 HTML로 만들고 안드로이드에서 실행하세요

SoifGo는 나만의 도구를 만들고 보관할 수 있는 무료 안드로이드 앱입니다: 계산기, 시뮬레이터, 교육 도구, 대시보드, 심지어 하드웨어 컨트롤러까지, 네이티브 안드로이드 코드를 작성하지 않고도.

HTML로 안드로이드 앱 만들기 — 네이티브 코드 없이

웹 페이지에서 가능한 모든 것은 SoifGo에서도 가능합니다. SoifGo는 당신의 도구를 HTML로 실행하고 폴더에 보관합니다. 계산기와 시뮬레이터부터 교육 도구와 대시보드까지, 필요하면 Bluetooth와 MQTT를 통한 하드웨어 제어까지.

웹 페이지를 작성할 수 있거나 AI 어시스턴트에게 요구 사항을 설명할 수 있다면, 자신만의 도구를 만들 수 있습니다.

SoifGo는 누구를 위한 것인가요?

📐 수학자와 학생

전문 계산기, 그래프와 함수, 시뮬레이션과 문제 해결 도구, 정확히 당신의 필요에 맞게.

🎓 교사와 강사

수업, 연습, 시험용 인터랙티브 도구. 학생들에게 파일을 보내 직접 실행하게 하세요.

🏗️ 모든 분야의 엔지니어

공학 계산기, 단위 변환, 개인 계산 표. 직장에서도 오프라인에서도 사용 가능.

🔌 메이커와 전자공학자

Arduino, ESP32, ESP8266, Raspberry Pi용 Bluetooth 및 MQTT 컨트롤러와 대시보드.

AI 어시스턴트에게 아이디어를 설명하고 HTML 코드를 받아 SoifGo에서 실행하세요.

안드로이드 폰에서 Arduino와 ESP32 제어 (Bluetooth 및 MQTT)

Bluetooth SPP(예: HC-05, HC-06), MQTT 또는 HTTP REST를 사용하는 모든 장치가 SoifGo와 작동합니다: Arduino, ESP32, ESP8266, Raspberry Pi.

Bluetooth로 LED, 모터, 릴레이 명령을 보내고, Bluetooth에서 MQTT로의 브리지를 만들고, 또는 센서의 실시간 대시보드를 구축하세요 — 모두 HTML로, 네이티브 코드 없이.

폴더 및 페이지 아카이빙

SoifGo는 작업을 정리해 보관할 수 있는 폴더와 페이지를 제공합니다. 각 페이지에는 40개 버튼과 10개 슬라이더가 있고, 각 버튼은 정의된 동작으로 설정할 수 있습니다. 폴더와 페이지 간의 탐색도 포함됩니다. 이렇게 많은 메뉴를 만들 수 있습니다.

버튼에는 미리 만들어진 디자인이 있습니다: 색상, 아이콘, 이름, 글꼴, 소리, 진동. 드래그 앤 드롭으로 이동할 수도 있습니다. 각 버튼은 보내기와 받기 같은 기본 동작을 가질 수 있습니다.

웹 동작, 온라인과 오프라인 모두

«웹 동작»(WebView)은 당신의 아이디어를 최대한의 기능으로 HTML로 실현하도록 도와줍니다, 온라인이든 오프라인이든. AI 어시스턴트에게 요구 사항을 설명하고 HTML 코드를 요청하기만 하면 됩니다. 그런 다음 두 가지 길이 있습니다:

  • 파일을 다운로드하고 SoifGo의 오프라인 웹 동작으로 로드(새로 고침)합니다.
  • 또는 코드를 복사해 SoifGo 내 HTML 편집기에 붙여넣습니다.

두 방법 모두 작동하며 웹 앱은 SoifGo 폴더에 보관됩니다. 계산기든, Bluetooth 컨트롤러든, IoT 모니터링이든, 무엇이든.

페이지당 40개의 서로 다른 웹 앱

페이지당 40개의 서로 다른 웹 앱을 가질 수 있습니다. 매번 AI 어시스턴트에게 요청할 필요가 없고, 오프라인에서도 사용할 수 있습니다. 동료와 친구에게 보내 다운로드하고 실행하게 할 수도 있습니다.

자주 묻는 질문

SoifGo는 Arduino와 전자공학 전용인가요?

아니요. 하드웨어 연결은 기능 중 하나일 뿐입니다. 도구가 HTML로 만들어지기 때문에 웹 페이지에서 가능한 모든 것 — 계산, 그래프, 시뮬레이션, 교육 도구 — 이 SoifGo에서도 가능합니다.

SoifGo는 무료인가요?

네. 완전히 무료이며 광고나 앱 내 구매가 없습니다.

인터넷 없이 작동하나요?

HTML 도구, Bluetooth, 휴대폰 센서는 인터넷 없이 작동합니다. MQTT와 HTTP만 네트워크 연결이 필요합니다.

어떤 하드웨어와 호환되나요?

Bluetooth SPP(예: HC-05, HC-06), MQTT 또는 HTTP REST를 사용하는 모든 장치. Arduino, ESP32, ESP8266, Raspberry Pi 포함.

시작하려면 무엇이 필요한가요?

기본적인 HTML 지식이면 충분합니다. 없어도 AI 어시스턴트에게 요구 사항을 설명하고 HTML 코드를 받을 수 있습니다. 튜토리얼과 준비된 예제는 메인 페이지에 있습니다.

시작할 준비가 되셨나요?

메인 페이지가 다운로드, 튜토리얼, 문서와 함께 열리고 한국어 번역이 자동으로 활성화됩니다.
