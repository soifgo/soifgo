Buat alat apa pun yang Anda inginkan dengan HTML dan jalankan di Android

SoifGo adalah aplikasi Android gratis untuk membuat dan mengarsipkan alat kustom: kalkulator, simulator, alat edukasi, dasbor, dan pengendali perangkat keras – tanpa memerlukan pemrograman Android asli (native).

SoifGo; aplikasi Android yang cepat dan efisien, untuk siapa ini?

Saat ini, sebagian besar kebutuhan – mulai dari perhitungan dan simulasi hingga dasbor dan panel kontrol kustom – dapat diimplementasikan dengan mudah. Mari kita fokus pada keunggulan SoifGo.

SoifGo menjalankan alat Anda dalam format HTML dan mengaturnya dalam folder. Karena HTML mendukung segala hal yang dimungkinkan di halaman web, bidang penerapannya sangat luas: dari kalkulator dan simulasi hingga alat pembelajaran, dasbor, dan bila diperlukan, kontrol perangkat keras melalui Bluetooth dan MQTT. Jika Anda dapat menulis halaman web atau memberi tahu asisten AI tentang kebutuhan Anda, Anda dapat membangun alat Anda sendiri.

Untuk siapa SoifGo dirancang?

📐 Matematikawan & Pelajar

Kalkulator khusus, grafik dan fungsi, simulasi, serta alat pemecahan masalah yang disesuaikan dengan kebutuhan Anda.

🎓 Guru & Instruktur

Alat interaktif untuk kelas, latihan, dan kuis. Kirimkan file kepada siswa atau peserta agar dapat langsung dijalankan.

🏗️ Insinyur di Berbagai Bidang

Kalkulator teknik, konverter satuan, dan spreadsheet pribadi yang selalu tersedia saat bekerja dan secara offline.

🔌 Penghobi & Pengembang Elektronik

Panel kontrol serta modul Bluetooth dan MQTT untuk Arduino, ESP32, ESP8266, dan Raspberry Pi.

💡 Siapa Saja yang Memiliki Ide

Sampaikan ide Anda kepada asisten AI, dapatkan kode HTML, dan jalankan di SoifGo.

Manajemen Folder dan Halaman

SoifGo menyediakan folder dan halaman untuk mengatur pekerjaan Anda dengan rapi. Di setiap halaman, Anda memiliki 40 tombol (buttons) dan 10 penggeser (sliders), dan Anda dapat mengonfigurasi setiap tombol untuk perilaku tertentu – termasuk navigasi antara folder dan halaman SoifGo untuk membuat menu bertingkat.

Tombol memiliki opsi desain bawaan: warna, ikon, nama, fon, suara, getaran, serta dukungan seret-dan-lepas (drag-and-drop). Setiap tombol dapat melakukan tugas input dan output dasar.

Perilaku Web, Online dan Offline

"Perilaku Web" (WebView) membantu Anda mewujudkan ide dan kebutuhan Anda dengan fleksibilitas maksimum dalam format HTML, baik saat online maupun offline. Cukup sampaikan kebutuhan Anda kepada asisten AI dan minta kode HTML-nya. Kemudian Anda memiliki dua pilihan:

  • Unduh file dan muat (muat ulang) menggunakan perilaku web offline di SoifGo.
  • Atau salin kode dan tempel (paste) ke dalam editor HTML bawaan SoifGo.

Kedua metode tersebut berfungsi, dan aplikasi web Anda diarsipkan di dalam folder SoifGo; baik itu kalkulator, pengendali Bluetooth, pemantauan IoT, atau alat kustom lainnya.

40 Aplikasi Web Berbeda di Setiap Halaman

Anda dapat memiliki hingga 40 aplikasi web berbeda di setiap halaman. Anda tidak perlu meminta asisten AI berulang kali, dan Anda dapat bekerja dengannya secara offline. Anda bahkan dapat membagikannya kepada rekan kerja, teman, atau peserta agar mereka dapat mengunduh dan menjalankannya.

Fitur-Fitur

🌐 WebView Penuh

Mesin browser modern: Canvas, SVG, WebGL, dan pustaka seperti Chart.js, D3, dan Three.js untuk grafik, simulasi, serta visualisasi 3D.

🧩 Mode Klasik

Tombol dan penggeser siap pakai tanpa kode apa pun untuk kontrol sederhana dan menu.

💾 Penyimpanan Lokal (LocalStorage)

Persistensi data menggunakan localStorage bahkan setelah aplikasi ditutup.

🟢 Sensor Ponsel

Cahaya sekitar, gerakan (akselerometer), dan magnetometer secara langsung dan real-time.

🎤 Mikrofon & Pengenalan Suara

Ubah ucapan menjadi teks untuk digunakan dalam alat Anda atau dikirimkan ke perangkat.

🔵 Bluetooth Serial

Mengirim dan menerima teks dengan HC-05, HC-06, JDY-31, Arduino, ESP32, dan Raspberry Pi.

🟣 Klien MQTT

Koneksi ke broker mana pun (tcp atau ssl), publikasi dan langganan (publish & subscribe), serta pemantauan status koneksi.

🟠 HTTP API

Mengirim JSON ke alamat mana pun, menerima dan mengekstrak nilai dari respons.

Pertanyaan yang Sering Diajukan (FAQ)

Apakah SoifGo hanya untuk Arduino dan elektronika?

Tidak. Koneksi perangkat keras hanyalah salah satu fitur. Karena alat berbasis HTML, segala hal yang dimungkinkan di halaman web (seperti perhitungan, grafik, simulasi, dan alat edukasi) juga berfungsi dengan lancar di SoifGo.

Apakah aplikasi SoifGo gratis?

Ya, sepenuhnya gratis tanpa iklan atau pembelian dalam aplikasi.

Apakah aplikasi ini berfungsi secara offline?

Alat HTML, Bluetooth, dan sensor ponsel berfungsi secara offline. Hanya MQTT dan HTTP yang membutuhkan koneksi internet atau jaringan lokal.

Sistem apa saja yang kompatibel untuk koneksi perangkat keras?

Perangkat apa pun yang mendukung Bluetooth SPP (seperti HC-05 dan HC-06), MQTT, atau HTTP REST; termasuk Arduino, ESP32, ESP8266, dan Raspberry Pi.

Apa yang saya perlukan untuk mulai?

Pengetahuan dasar tentang HTML sudah cukup. Bahkan tanpa itu, Anda dapat meminta kode HTML kepada asisten AI. Tutorial dan contoh siap pakai tersedia di halaman utama.
