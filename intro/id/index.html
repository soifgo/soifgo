SoifGo — Buat alat apa pun yang Anda bayangkan dengan HTML dan jalankan di Android

SoifGo adalah aplikasi Android gratis untuk membuat dan mengarsipkan alat kustom: kalkulator, simulator, alat pendidikan, dasbor, bahkan pengendali perangkat keras, tanpa menulis kode Android native.

Buat aplikasi Android dengan HTML — tanpa kode native

Semua yang mungkin di halaman web juga mungkin di SoifGo. SoifGo menjalankan alat Anda sebagai HTML dan mengarsipkannya dalam folder. Dari kalkulator dan simulator, hingga alat pendidikan dan dasbor, dan bila perlu, kontrol perangkat keras melalui Bluetooth dan MQTT.

Jika Anda bisa menulis halaman web, atau menjelaskan kebutuhan Anda kepada asisten AI, Anda bisa membuat alat Anda sendiri.

Untuk siapa SoifGo?

📐 Matematikawan dan mahasiswa

Kalkulator khusus, grafik dan fungsi, simulasi dan alat pemecahan masalah, persis sesuai kebutuhan Anda.

🎓 Guru dan instruktur

Alat interaktif untuk kelas, latihan, dan ujian. Kirim file ke siswa agar mereka menjalankannya sendiri.

🏗️ Insinyur segala bidang

Kalkulator teknik, konversi satuan, dan tabel perhitungan pribadi yang tersedia di tempat kerja dan offline.

🔌 Maker dan pegiat elektronik

Pengendali dan dasbor Bluetooth dan MQTT untuk Arduino, ESP32, ESP8266, dan Raspberry Pi.

💡 Siapa saja yang punya ide

Jelaskan ide kepada asisten AI, dapatkan kode HTML, dan jalankan di SoifGo.

Kontrol Arduino dan ESP32 via Bluetooth dan MQTT dari ponsel Android

Perangkat apa pun yang menggunakan Bluetooth SPP (seperti HC-05 dan HC-06), MQTT, atau HTTP REST bekerja dengan SoifGo: Arduino, ESP32, ESP8266, dan Raspberry Pi.

Kirim perintah LED, motor, dan relai via Bluetooth, buat jembatan Bluetooth ke MQTT, atau buat dasbor langsung untuk sensor — semuanya dengan HTML, tanpa kode native.

Pengarsipan folder dan halaman

SoifGo memberi Anda folder dan halaman untuk mengarsipkan pekerjaan Anda secara tertata. Di setiap halaman Anda memiliki 40 tombol dan 10 slider, dan setiap tombol dapat dikonfigurasi untuk perilaku yang ditentukan, termasuk navigasi antar folder dan halaman. Dengan cara ini Anda bisa membuat banyak menu.

Tombol memiliki desain siap pakai: warna, ikon, nama, font, suara, dan getaran. Juga dapat dipindahkan dengan drag and drop. Setiap tombol dapat memiliki perilaku dasar seperti kirim dan terima.

Perilaku web, online dan offline

«Perilaku web» (WebView) membantu Anda mewujudkan ide dengan kemampuan maksimal dan dalam HTML, baik online maupun offline. Cukup jelaskan kebutuhan Anda kepada asisten AI dan minta kode HTML. Lalu ada dua jalan:

  • Unduh file dan muat (muat ulang) dengan perilaku web offline di SoifGo.
  • Atau salin kode dan tempel di editor HTML di dalam SoifGo.

Kedua metode bekerja dan aplikasi web Anda diarsipkan di folder SoifGo. Entah kalkulator, pengendali Bluetooth, pemantauan IoT, atau apa pun.

40 aplikasi web berbeda per halaman

Anda dapat memiliki 40 aplikasi web berbeda per halaman. Tidak perlu meminta kepada asisten AI setiap kali, dan Anda dapat menggunakannya secara offline. Anda bahkan bisa mengirimkannya ke kolega dan teman agar mereka mengunduh dan menjalankannya.

Fitur SoifGo

🌐 WebView lengkap

Mesin browser modern: Canvas, SVG, WebGL, dan pustaka seperti Chart.js, D3, dan Three.js untuk grafik, simulasi, dan tampilan 3D.

🧩 Mode klasik

Tombol dan slider siap pakai, tanpa kode, untuk kontrol dan menu sederhana.

💾 Penyimpanan lokal

Menyimpan data dengan localStorage bahkan setelah aplikasi ditutup.

🟢 Sensor ponsel

Cahaya sekitar, gerakan (akselerometer), dan magnetometer secara real-time.

🎤 Mikrofon dan pengenalan suara

Mengubah suara menjadi teks dan menggunakannya di alat Anda atau mengirim ke perangkat.

🔵 Bluetooth serial

Mengirim dan menerima teks dengan HC-05, HC-06, JDY-31, Arduino, ESP32, dan Raspberry Pi.

🟣 Klien MQTT

Terhubung ke broker mana pun (tcp atau ssl), publish dan subscribe, serta memeriksa status.

🟠 HTTP API

Kirim JSON ke alamat apa pun dan terima serta ekstrak nilai dari respons.

Pertanyaan yang sering diajukan

Apakah SoifGo hanya untuk Arduino dan elektronik?

Tidak. Koneksi perangkat keras hanyalah salah satu fitur. Karena alat dibuat dengan HTML, semua yang mungkin di halaman web — perhitungan, grafik, simulasi, dan alat pendidikan — juga mungkin di SoifGo.

Apakah SoifGo gratis?

Ya. Sepenuhnya gratis, tanpa iklan atau pembelian dalam aplikasi.

Apakah berfungsi tanpa koneksi internet?

Alat HTML, Bluetooth, dan sensor ponsel berfungsi tanpa internet. Hanya MQTT dan HTTP yang memerlukan koneksi jaringan.

Perangkat keras apa yang kompatibel dengan SoifGo?

Perangkat apa pun yang menggunakan Bluetooth SPP (seperti HC-05 dan HC-06), MQTT, atau HTTP REST, termasuk Arduino, ESP32, ESP8266, dan Raspberry Pi.

Apa yang saya perlukan untuk memulai?

Pengetahuan HTML dasar sudah cukup. Bahkan tanpa itu, Anda dapat menjelaskan kebutuhan Anda kepada asisten AI dan mendapatkan kode HTML. Tutorial dan contoh siap pakai tersedia di halaman utama.

Siap memulai?

Halaman utama terbuka dengan unduhan, tutorial, dan dokumentasi, serta terjemahan Bahasa Indonesia diaktifkan otomatis.
