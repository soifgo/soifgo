从安卓手机控制 Arduino 和 ESP32（蓝牙和 MQTT）

任何使用蓝牙 SPP（如 HC-05 和 HC-06）、 MQTT 或 HTTP REST 的设备都能与 SoifGo 配合： Arduino、ESP32、ESP8266 和树莓派。

通过蓝牙发送 LED、电机和继电器命令，创建蓝牙到 MQTT 的桥接， 或构建实时传感器仪表盘 —— 全部用 HTML，无需原生代码。

文件夹和页面归档

SoifGo 提供文件夹和页面，让你有序地归档工作。 每页有 40 个按钮和 10 个滑块，每个按钮 都可以配置为定义的行为，包括在文件夹和页面之间导航。 这样就可以创建许多菜单。

按钮有现成的设计：颜色、图标、名称、字体、声音和振动。 还可以拖放移动。每个按钮都可以有发送和接收等基本行为。

网页行为，在线和离线都可以

「网页行为」（WebView）帮助你以最大的能力、用 HTML 实现你的想法， 无论在线还是离线。只需向 AI 助手描述你的需求，索取 HTML 代码。然后有两条路：

  • 下载文件，用 SoifGo 的离线网页行为加载（重新加载）。
  • 或者复制代码，粘贴到 SoifGo 内的 HTML 编辑器中。

两种方法都有效，你的网页应用会归档到 SoifGo 的文件夹中。 无论是计算器、蓝牙控制器、物联网监控还是任何其他东西。

每页 40 个不同的网页应用

每页可以有 40 个不同的网页应用。不必每次都向 AI 助手索取，离线时也可以使用它们。 甚至可以把它们发给同事和朋友，让他们下载并运行。

SoifGo 功能

🌐 完整 WebView

现代浏览器引擎：Canvas、SVG、WebGL，以及 Chart.js、D3 和 Three.js 等库，用于图表、模拟和 3D 显示。

🧩 经典模式

现成的按钮和滑块，无需任何代码，用于简单的控制和菜单。

🟢 手机传感器

环境光、运动（加速度计）和磁力计，实时更新。

🔵 串口蓝牙

🟣 MQTT 客户端

连接到任何 broker（tcp 或 ssl）、publish 和 subscribe，并检查连接状态。

🟠 HTTP API

向任何地址发送 JSON，接收并从响应中提取值。

常见问题

SoifGo 只适用于 Arduino 和电子设备吗？

不是。硬件连接只是其中一项功能。因为工具是用 HTML 构建的，网页上能做到的一切 —— 计算、图表、模拟和教学工具 —— 在 SoifGo 中也能实现。

SoifGo 免费吗？

是的。完全免费，无广告，无应用内购买。

断网时可以使用吗？

HTML 工具、蓝牙和手机传感器无需联网即可使用。只有 MQTT 和 HTTP 需要网络连接。

SoifGo 兼容哪些硬件？

任何使用蓝牙 SPP（如 HC-05 和 HC-06）、MQTT 或 HTTP REST 的设备，包括 Arduino、ESP32、ESP8266 和树莓派。

开始使用需要什么？

基础 HTML 知识就够了。即使没有，也可以向 AI 助手描述你的需求并获取 HTML 代码。教程和现成示例在主页上。
