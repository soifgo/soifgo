使用 HTML 创建您想象的任何工具并在 Android 上运行

SoifGo 是一款免费的 Android 应用程序，用于创建和存档自定义工具（如计算器、模拟器、教育工具、仪表板和硬件控制器），无需具备原生 Android 编程知识。

SoifGo；一款快速高效的 Android 应用，它适合谁？

如今，大多数需求——从计算和模拟到自定义仪表板和控制面板——都可以轻松实现。让我们聚焦于 SoifGo 的优势。

SoifGo 以 HTML 格式运行您的工具并将其组织到文件夹中。由于 HTML 支持网页上可能的一切，其应用领域极其广泛：从计算器和模拟器到学习工具、仪表板，以及在需要时通过蓝牙和 MQTT 进行硬件控制。如果您会编写网页，或者能向 AI 助手解释您的需求，您就可以构建自己的工具。

文件夹和页面管理

SoifGo 提供文件夹和页面，帮助您整洁地组织工作。每个页面上有 40 个按钮 (buttons) 和 10 个滑块 (sliders)，您可以为特定行为配置每个按钮——包括在 SoifGo 文件夹和页面之间导航以创建多级菜单。

按钮具有预定义的选项：颜色、图标、名称、字体、声音、振动和拖放 (drag-and-drop) 支持。每个按钮都可以执行基本的输入和输出任务。

网页行为（在线和离线）

“网页行为”(WebView) 帮助您在在线或离线时，以 HTML 格式最大程度地灵活实现您的想法和需求。只需向 AI 助手提出您的请求并索取 HTML 代码。然后您有两种选择：

  • 下载文件并在 SoifGo 中使用离线网页行为加载（重新加载）它。
  • 或者复制代码并将其粘贴到 SoifGo 内置的 HTML 编辑器中。

这两种方法都有效，您的网页应用将存档在 SoifGo 文件夹中；无论是计算器、蓝牙控制器、物联网监控还是任何其他自定义工具。

每个页面多达 40 个不同的网页应用

您可以在每个页面上拥有多达 40 个不同的网页应用。您无需反复询问 AI 助手，并且可以离线使用它们。您甚至可以与同事、朋友或学员分享它们以供下载和运行。

功能特性

🌐 完整 WebView

现代浏览器引擎：Canvas、SVG、WebGL 以及用于图表、模拟和 3D 可视化的库（如 Chart.js、D3、Three.js）。

🧩 经典模式 (Classic Mode)

无需任何代码的现成按钮和滑块，用于简单控制和快捷菜单。

💾 本地存储 (LocalStorage)

即使在关闭应用程序后，也使用 localStorage 保持数据持久性。

🟢 手机传感器

实时且现场的环境光、运动（加速度计）和磁力计。

🎤 麦克风和语音识别

将语音转换为文本，以便在您的工具中使用或发送到设备。

🔵 蓝牙串口 (Bluetooth Serial)

通过 HC-05、HC-06、JDY-31、Arduino、ESP32 和 Raspberry Pi 发送和接收文本。

🟣 MQTT 客户端

连接到任何代理（tcp 或 ssl）、发布和订阅 (publish & subscribe) 以及连接状态监控。

🟠 HTTP API

向任何地址发送 JSON，接收并从响应 (response) 中提取值。

常见问题 (FAQ)

SoifGo 仅适用于 Arduino 和电子产品吗？

不是。硬件连接只是功能之一。由于工具基于 HTML，网页上可能的一切（如计算、图表、模拟和教育工具）在 SoifGo 中也能完美运行。

SoifGo 应用是免费的吗？

是的，完全免费，没有广告或内购。

它能离线工作吗？

HTML 工具、蓝牙和手机传感器可以离线工作。只有 MQTT 和 HTTP 需要互联网或本地网络连接。

哪些系统兼容硬件连接？

任何支持蓝牙 SPP（如 HC-05 和 HC-06）、MQTT 或 HTTP REST 的设备；包括 Arduino、ESP32、ESP8266 和 Raspberry Pi。

开始使用需要什么？

基本的 HTML 知识就足够了。即使没有，您也可以向 AI 助手索取 HTML 代码。主页上有教程和现成的示例。
