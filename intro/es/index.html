Crea cualquier herramienta que imagines con HTML y ejecútala en Android

SoifGo es una aplicación de Android gratuita para crear y archivar herramientas personalizadas: calculadoras, simuladores, herramientas educativas, paneles y controladores de hardware, sin necesidad de programación nativa en Android.

SoifGo; una aplicación de Android rápida y eficiente, ¿para quién es?

Hoy en día, la mayoría de las necesidades —desde cálculos y simulaciones hasta paneles de control y tableros personalizados— se pueden implementar fácilmente. Concentrémonos en las características principales de SoifGo.

SoifGo ejecuta tus herramientas en formato HTML y las organiza en carpetas. Dado que HTML admite todo lo que es posible en las páginas web, su campo de aplicación es extremadamente amplio: desde calculadoras y simulaciones hasta herramientas educativas, paneles de control y, cuando es necesario, control de hardware mediante Bluetooth y MQTT. Si puedes escribir una página web o explicarle tus necesidades a un asistente de IA, puedes construir tu propia herramienta.

Cuéntale tu idea a un asistente de IA, obtén el código HTML y ejecútalo en SoifGo.

Gestión de carpetas y páginas

SoifGo te ofrece carpetas y páginas para organizar tu trabajo de forma ordenada. En cada página tienes 40 botones y 10 controles deslizantes (sliders), y puedes configurar cada botón para comportamientos específicos; incluyendo la navegación entre carpetas y páginas de SoifGo para crear menús multinivel.

Los botones cuentan con opciones de diseño predefinidas: color, icono, nombre, fuente, sonido, vibración y soporte para arrastrar y soltar (drag-and-drop). Cada botón puede realizar tareas básicas de entrada y salida.

Comportamiento web, en línea y sin conexión

El "Comportamiento Web" (WebView) te ayuda a plasmar tus ideas y necesidades con la máxima flexibilidad en formato HTML, ya estés conectado o no. Solo dile tus requerimientos a un asistente de IA y pídele el código HTML. Luego tienes dos opciones:

  • Descarga el archivo y cárgalo (recárgalo) utilizando el comportamiento web sin conexión en SoifGo.
  • O copia el código y pégalo en el editor HTML integrado de SoifGo.

Ambos métodos funcionan, y tu aplicación web se archiva en la carpeta de SoifGo; ya sea una calculadora, un controlador Bluetooth, supervisión de IoT o cualquier otra herramienta personalizada.

40 aplicaciones web diferentes en cada página

Puedes tener hasta 40 aplicaciones web diferentes en cada página. No necesitas pedírselo repetidamente al asistente de IA, y puedes trabajar con ellas sin conexión a Internet. Incluso puedes compartirlas con colegas, amigos o aprendices para que las descarguen y ejecuten.

Características

🌐 WebView completo

Motor de navegador moderno: Canvas, SVG, WebGL y librerías como Chart.js, D3 y Three.js para gráficos, simulaciones y visualización 3D.

🧩 Modo clásico

Botones y controles deslizantes preparados sin necesidad de código para controles simples y menús.

💾 Almacenamiento local

Persistencia de datos mediante localStorage incluso después de cerrar la aplicación.

🟢 Sensores del teléfono

Luz ambiental, movimiento (acelerómetro) y magnetómetro en tiempo real y en directo.

🎤 Micrófono y reconocimiento de voz

Convierte voz en texto y úsala en tus herramientas o envíala a los dispositivos.

🔵 Bluetooth Serial

Envío y recepción de texto con HC-05, HC-06, JDY-31, Arduino, ESP32 y Raspberry Pi.

🟣 Cliente MQTT

Conexión a cualquier broker (tcp o ssl), publicación y suscripción, y supervisión del estado de la conexión.

🟠 HTTP API

Envío de JSON a cualquier dirección, recepción y extracción de valores de la respuesta.

Preguntas frecuentes (FAQ)

¿SoifGo es solo para Arduino y electrónica?

No. La conexión de hardware es solo una de sus características. Dado que las herramientas se basan en HTML, todo lo posible en páginas web (como cálculos, gráficos, simulaciones y herramientas educativas) funciona sin problemas en SoifGo.

¿La aplicación SoifGo es gratuita?

Sí, es completamente gratuita, sin anuncios ni compras dentro de la aplicación.

¿Funciona sin conexión a Internet?

Las herramientas HTML, el Bluetooth y los sensores del teléfono funcionan sin conexión. Solo MQTT y HTTP requieren conexión a Internet o a una red local.

¿Qué sistemas son compatibles para la conexión de hardware?

Cualquier dispositivo que admita Bluetooth SPP (como HC-05 y HC-06), MQTT o HTTP REST; incluyendo Arduino, ESP32, ESP8266 y Raspberry Pi.

¿Qué necesito para empezar?

Basta con conocimientos básicos de HTML. Incluso sin ellos, puedes pedirle el código HTML a un asistente de IA. En la página principal hay tutoriales y ejemplos listos para usar.
