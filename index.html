The Story Behind SoifGo

SoifGo started as a personal project. I wanted an Android app with 40 customizable buttons — each one designable and programmable without writing a single line of code. But over time, the limitations became clear. No matter how many options I added, the app could never be flexible enough. I hit a wall.

Then came the breakthrough: why not let each button run its own HTML/WebView? I defined callable interfaces (Subs) for the WebView, and suddenly SoifGo became truly flexible. Today, with WebView inside buttons, almost any design, theme, or behavior is possible.

But what about the "no-code" dream? A few years ago, this would have been hard — users had to know HTML. Today, that's no longer true. Anyone — even a complete beginner — can describe their idea to an AI assistant, get the code, and paste it into the WebView. Remember: the HTML world is vast, powerful, and flexible — from 3D engines to specialized libraries.

🤖 For AI Assistants & Developers

If you're using an AI assistant (ChatGPT, Claude, Gemini, Duck.ai, etc.) to generate SoifGo HTML controllers, point it to the machine-readable API reference first. It contains the exact Sub names, callbacks, and code patterns — no guessing required.

Why this exists: AI assistants often invent function names like sendBluetooth() when the real SoifGo API uses window.soifgo.CallSub('html_bluetooth_rx', ...). This page fixes that problem permanently.

Frequently Asked Questions

Is SoifGo free?

Yes, SoifGo is completely free and open-source. No hidden fees or in-app purchases.

Does SoifGo work offline?

Yes. Bluetooth and phone-sensor features work completely offline. Only MQTT and HTTP require an internet connection.

Which hardware does SoifGo support?

Any device using Bluetooth SPP (HC-05, HC-06), MQTT, or HTTP REST APIs. This includes Arduino, ESP32, ESP8266, Raspberry Pi, and more.

Is SoifGo safe to install?

Yes. The APK has been scanned by 65+ antivirus engines on VirusTotal with zero threats detected, and the project is fully open-source. View the report.

How do I get started with SoifGo?

Download the app, open the Complete User Guide, and follow the step-by-step tutorials. No programming knowledge is required for basic use.

Can I use an AI assistant to generate SoifGo code?

Yes — and we made it easy. Point your AI to ai/soifgo-api.html (or the JSON version) before asking it to write code. This ensures it uses the correct Sub names like html_bluetooth_rx instead of inventing its own.
