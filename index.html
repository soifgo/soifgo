ℹ️ About SoifGo — IoT Controller for Android

SoifGo is an Android application that provides advanced control using buttons and seek bars. It supports Bluetooth and MQTT protocols, making it ideal for controlling ESP32, Arduino, HC‑05, and ESP8266 devices.

Developer: Saeid Moghadam

❓ Frequently Asked Questions

How to connect ESP32 to Android via Bluetooth? SoifGo allows you to easily connect and control ESP32 via Bluetooth. Install the app, pair your device, and start sending commands through buttons and seek bars.
What devices does SoifGo support? SoifGo supports ESP32, Arduino, HC‑05, HC‑06, ESP8266, and any device that communicates via Bluetooth SPP or MQTT protocol.
Is SoifGo free and open‑source? Yes! SoifGo is completely free to download and use. The source code is available for developers who want to contribute or customize it.
Can I use SoifGo for robotics projects? Absolutely! SoifGo is perfect for controlling robots with Bluetooth modules like HC‑05 and HC‑06. You can have up to 40 separate notes (commands) per page, each with send and receive capabilities. This allows you to send motion data to your robot via Bluetooth and reflect the same data back to monitor its status. Additionally, you can use the WebView feature in SoifGo to build your own custom user interface with HTML and CSS. By following the Bluetooth send/receive instructions, you can establish full two-way communication with your robot. Everything depends on your creativity and skills — SoifGo provides the tools, and you build the experience!
Does SoifGo support MQTT? Yes, SoifGo includes MQTT support, allowing you to control your IoT devices over the internet in addition to Bluetooth.
What languages does SoifGo support? SoifGo supports 22 languages including English, Spanish, Chinese, Arabic, Hindi, Russian, French, German, Japanese, Persian, and many more.
How to control Arduino with Bluetooth from Android? Install SoifGo, pair with your Arduino's HC‑05/06 module, and use the buttons and seek bars to send commands.
Is SoifGo available on Google Play? SoifGo is currently available as a direct download (APK) and on APKPure. Google Play release is coming soon.
Can SoifGo be used to build custom apps?

Yes, absolutely! SoifGo acts as a powerful platform for building lightweight, custom IoT control interfaces without needing traditional Android development knowledge. You can create your app in two ways:

  • No-Code UI Builder: Easily create folders, multi-page layouts, shortcut buttons, and custom seek bars directly through the built-in visual interface.
  • Advanced WebView (HTML/JS): For complete design freedom, you can link buttons to open offline HTML files. This opens a native WebView environment where you can run custom interactive layouts, render animations, and leverage a JavaScript bridge to access phone sensors or send Bluetooth commands.

Pro Tip: Today, you don't even need to write HTML/JavaScript from scratch. You can simply ask any modern AI tool to generate the exact web-based controller layout you want and paste it into SoifGo. This turns the app into an incredibly fast, flexible rapid-prototyping ecosystem for your hardware projects.
