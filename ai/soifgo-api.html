1. Bridge Namespace

All communication between an HTML page (running inside SoifGo's WebView) and the SoifGo app goes through a single global object: window.soifgo. 

window.soifgo.CallSub(subName, hasReturn, ...args)
Parameter Type Description
subName string The exact name of the Sub to call (case-sensitive).
hasReturn boolean true if the Sub returns data; false otherwise.
...args any Arguments passed to the Sub.
⚠️ Important: window.soifgo only exists when the HTML is running inside SoifGo's WebView. If you open the same HTML in a normal browser, the bridge is undefined. Always guard with if (window.soifgo) { ... }.

2. Bluetooth — Send (HTML → Device)

To send a text string from your HTML page to the connected Bluetooth device (HC-05, HC-06, ESP32, etc.), call the html_bluetooth_rx Sub.

Action Sub Name Syntax
Send text to Bluetooth html_bluetooth_rx window.soifgo.CallSub('html_bluetooth_rx', true, 'LED_ON')

Example

function sendBluetooth(text) {
  if (window.soifgo) {
    window.soifgo.CallSub('html_bluetooth_rx', true, text);
  }
}

// Usage
sendBluetooth('LED_ON');
sendBluetooth('LED_OFF');
sendBluetooth('GET_DATA');
💡 Note: The name html_bluetooth_rx means "HTML → Bluetooth rx". It may look backwards, but this is the actual SoifGo Sub name. Do not rename it.

3. Bluetooth — Receive (Device → HTML)

When the Bluetooth device sends data back to SoifGo, the app calls a JavaScript function named html_bluetooth_tx(data). You must define this function and attach it to window.

Action Callback Function
Receive data from Bluetooth function html_bluetooth_tx(data) { }

Example

function html_bluetooth_tx(data) {
  console.log('Received from Bluetooth:', data);
  document.getElementById('output').innerText = data;
}

// CRITICAL: attach to window
window.html_bluetooth_tx = html_bluetooth_tx;
⚠️ Required: You must write window.html_bluetooth_tx = html_bluetooth_tx; after defining the function. Without this line, SoifGo cannot find your callback.

4. Phone Sensors

SoifGo can stream phone sensor data into your HTML page. Each sensor has an activate Sub (which you call once) and one or more callback functions (which SoifGo calls repeatedly with new data).

Sensor Activate Sub Callback Function(s)
💡 Light sensor_light html_sensor_light(data)
🏃 Motion (X axis) sensor_move html_sensor_movex(data)
🏃 Motion (Y axis) sensor_move html_sensor_movey(data)
🧲 Magnetic field sensor_magno html_sensor_magno(data)

Activate + receive example

// Define callbacks
function html_sensor_light(data) {
  document.getElementById('light').innerText = 'Light: ' + data;
}
function html_sensor_movex(data) {
  document.getElementById('movex').innerText = 'X: ' + data;
}
function html_sensor_movey(data) {
  document.getElementById('movey').innerText = 'Y: ' + data;
}
function html_sensor_magno(data) {
  document.getElementById('magno').innerText = 'Magnetic: ' + data;
}

// Attach all to window
window.html_sensor_light = html_sensor_light;
window.html_sensor_movex = html_sensor_movex;
window.html_sensor_movey = html_sensor_movey;
window.html_sensor_magno = html_sensor_magno;

// Activate sensors on page load
window.onload = function () {
  if (window.soifgo) {
    window.soifgo.CallSub('sensor_light');
    window.soifgo.CallSub('sensor_move');
    window.soifgo.CallSub('sensor_magno');
  }
};

5. Complete Working Example

This is a minimal, fully-functional SoifGo HTML page that:

  • Sends LED_ON / LED_OFF to Bluetooth
  • Receives Bluetooth data and displays it
  • Streams light sensor data
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>SoifGo Controller</title>
  <style>
    body { font-family: sans-serif; padding: 20px; background: #111; color: #eee; }
    button { padding: 14px 20px; margin: 6px; border: none; border-radius: 8px; font-size: 16px; color: white; }
    .on  { background: #16a34a; }
    .off { background: #dc2626; }
    .data { background: #2563eb; }
    .card { background: #1f2937; padding: 14px; border-radius: 10px; margin: 10px 0; }
  </style>
</head>
<body>

  <h2>SoifGo Controller</h2>

  <button class="on"  onclick="sendBluetooth('LED_ON')">LED ON</button>
  <button class="off" onclick="sendBluetooth('LED_OFF')">LED OFF</button>
  <button class="data" onclick="sendBluetooth('GET_DATA')">Get Data</button>

  <div class="card">Bluetooth: <span id="bt">—</span></div>
  <div class="card">Light sensor: <span id="light">—</span></div>

  <script>
    // ---- Send to Bluetooth ----
    function sendBluetooth(text) {
      if (window.soifgo) {
        window.soifgo.CallSub('html_bluetooth_rx', true, text);
      }
    }

    // ---- Receive from Bluetooth ----
    function html_bluetooth_tx(data) {
      document.getElementById('bt').innerText = data;
    }
    window.html_bluetooth_tx = html_bluetooth_tx;

    // ---- Light sensor ----
    function html_sensor_light(data) {
      document.getElementById('light').innerText = data;
    }
    window.html_sensor_light = html_sensor_light;

    // ---- Activate sensors ----
    window.onload = function () {
      if (window.soifgo) {
        window.soifgo.CallSub('sensor_light');
      } else {
        document.getElementById('bt').innerText = 'SoifGo not detected';
      }
    };
  </script>

</body>
</html>

6. Rules for AI Assistants

  1. Never invent Sub names. Use only: html_bluetooth_rx, sensor_light, sensor_move, sensor_magno.
  2. Case matters. html_bluetooth_rx is not html_bluetooth_RX or html_Bluetooth_rx.
  3. Always attach callbacks to window. 
    window.html_bluetooth_tx = html_bluetooth_tx;
  4. Guard the bridge. Wrap all window.soifgo.CallSub calls in if (window.soifgo) { ... }.
  5. Do not use fetch() for local files. HTML runs inside SoifGo's WebView; use the Sub bridge for device communication instead.
  6. For MQTT and HTTP, SoifGo has separate Subs. Refer to the main documentation for those.
  7. Do not rename html_bluetooth_rx to sendBluetooth in your generated code. You may wrap it in a helper function named sendBluetooth, but the actual Sub call must remain html_bluetooth_rx.
