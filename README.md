# 📱 About SoifGo

SoifGo is an advanced Android application designed for makers, developers, electronics enthusiasts, IoT engineers, CNC operators, and automation enthusiasts.

The platform combines Bluetooth communication, MQTT networking, API integration, HTML-based interfaces, programmable controls, RGB lighting systems, CNC machine control, sensor monitoring, and mobile automation into a single customizable environment.

SoifGo is more than a mobile application. It serves as the central platform powering projects such as **RANGMANG** and **CMI209**.

---

# 🚀 Ecosystem Projects

## 🌈 RANGMANG

**RANGMANG** is an open-source RGB lighting controller ecosystem designed for addressable LED strips.

### Features

- Open-source hardware and software
- Bluetooth control through SoifGo
- Real-time RGB management
- Custom color presets
- Dynamic lighting effects
- Mobile-based configuration
- Effect storage and management

### Supported LEDs

- WS2811
- WS2812
- WS2813
- WS2815

RANGMANG allows users to create, manage, and control advanced RGB lighting systems directly from their Android devices using SoifGo.

---

## ⚙️ CMI209

**CMI209** is a Bluetooth-enabled CNC controller platform integrated with SoifGo.

### Features

- Bluetooth communication
- CNC machine control
- Mobile operation interface
- Real-time monitoring
- Command transmission
- Custom workflow management

### Mini CAD/CAM

CMI209 includes a lightweight Mini CAD/CAM environment integrated into SoifGo.

Capabilities include:

- Basic CAD design
- Toolpath preparation
- CNC workflow management
- Mobile manufacturing support
- Direct Bluetooth machine communication

This enables rapid CNC operation and prototyping directly from an Android device.
